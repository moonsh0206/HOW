# Phase 3.7 현재 픽률 및 요약 내부 배치 보완

2026-11-03 로컬 수정. 이전 진단 보고서의 패널 외부 배치는 본 변경으로 대체한다.

## 배치

`#detail-page-statistics`는 `.detail-summary` 하나만 포함한다. 내부 grid의 왼쪽 첫 행은 통계 4개, 왼쪽 둘째 행은 메타 점수·즐겨찾기·조건·출처이다. 오른쪽은 두 행을 차지하는 `.detail-summary-side`이며 카운터 다음에 `#pick-history` 하나만 생성한다. 이력 영역 자체의 외곽 카드 테두리와 배경은 제거하고 구분선만 둔다. 최소 높이 260px, 실제 SVG 높이 180px이다.

700px 이하에서는 통계 → 카운터 → 그래프 → 부가 정보 순서로 전환한다. 기존 모바일 메인 영웅 카드 CSS는 변경하지 않았다. 1440px은 grid, 390px은 세로 배치가 적용되는 CSS 조건이다. 실제 화면에서 측정한 결과는 아니다.

## 현재 관측값

`withCurrentPickHistory()`는 현재 통계 모델의 records에서 해당 영웅의 pickRate를 읽는다. 플랫폼·모드·지역·등급·전장 5개 필터가 모두 명시되고 현재 선택과 일치하며, 원래 fetchedAt과 0–100 범위의 숫자가 유효할 때만 결합한다. null과 0을 구분한다. 별도 API 호출이나 임의 수치·현재 시각 생성은 없다.

캐시 재사용도 원래 HOW fetchedAt을 유지한다. 현재 응답에는 검증된 패치 정보가 없으므로 과거 관측과 연결하지 않는다. 같은 시각은 한 점만 출력하며, 해당 시각의 과거 값과 다르면 현재 응답 값을 표시한다. 다른 시각에 같은 픽률이 관측된 것은 서로 다른 실제 관측으로 유지한다. 캐시의 원래 시각이 선택 기간보다 오래되어도 현재 값은 오래된 데이터 표시와 원래 시각으로 제시하고 과거 기록인 것처럼 새 날짜에 저장하지 않는다.

StatisticsService에는 표시용 `cached`, `providerAgeSeconds` 메타데이터만 추가했다. 요청·캐시 TTL·fallback 정책은 그대로다. HOW 캐시 재사용, 갱신 실패 시 오래된 값, 제공처 Age 헤더 유무를 구분한다. Age가 없으면 제공처 캐시 여부 미확인으로 표시한다. 원본 집계 시각은 여전히 미제공이다.

이력 로딩/실패 중에도 유효한 현재 관측점과 수치를 표시하며 실패 안내·재시도는 유지한다. 저장 스냅샷은 전체 등급 1개/다이아몬드 0개로 변경하지 않았다. 현재 API 값을 장기 보관하려면 별도 수집이 필요하다.

## 검증과 한계

- 전체 테스트 79개 통과. 실제 아카이브를 읽는 겐지 상세 통합 테스트에 현재 응답 결합·재렌더 시 중복 ID 방지·필터 전환 시 현재 값 혼합 방지 검증을 추가했다.
- 별도 테스트: 정확한 코호트·원래 조회 시각·캐시/오래된 값 메타데이터·0/null·동일 시각 중복·이력 실패 중 현재 점 표시.
- 프로덕션 빌드 및 Pages 경로 검증 통과.
- 브라우저 도구는 `No browser is available`을 반환했다. 1440px/390px 실제 배치·SVG 잘림·터치·스크린샷 검증은 미완료이며 DOM 테스트를 시각 검증으로 간주하지 않았다.
- Meta Score v2·카운터 DB·HOT·즐겨찾기·티어 산정 정책은 변경하지 않았다. Push·배포·추가 데이터 수집도 하지 않았다.
