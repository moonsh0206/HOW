## 2. 후보 모델과 수학적 정의

W/P/B/R은 점수 범위 0–100으로 표현한다. 동일 값을 평균 동률 백분위로 처리하며 역할 내 비교만 한다. 최종 점수는 소수점 10자리로 정리하고 동점은 같은 competition rank(1,1,3), 표시 순서는 key로 안정화한다.

| ID | 점수 | 현재 계산 여부 |
|---|---|---|
| A | 0.65Qw + 0.25Qp + 0.10Qb | 운영 v2 대조군 |
| B20 | (0.45Qw + 0.25Qp + 0.20Qb) / 0.90 | 예비 부분 모델 |
| B15 | (0.45Qw + 0.30Qp + 0.15Qb) / 0.90 | 밴 영향 대조 부분 모델 |
| C20 | 0.45Qw + 0.25Qp + 0.20Qb + 0.10R | R 없어 미계산 |
| C15 | 0.45Qw + 0.30Qp + 0.15Qb + 0.10R | R 없어 미계산 |

B20의 실제 가중치는 **50% / 27.777…% / 22.222…%**다. 따라서 '밴률 20%'는 전체 C20의 계수이며 현재 B20에서 밴률이 차지하는 비중은 약 22.22%이다. B15는 50% / 33.333…% / 16.666…%이다. 부분 모델을 최종 v3라고 부르지 않는다.

### 실제 승률 차이 정규화 대조

백분위 Qw 대신 아래 승률 점수를 사용한 A/B20/B15 대조군을 각각 s=5, s=10으로 실행했다.

`F_s(w) = clamp(50 + s × (w - 50), 0, 100)`

여기서 w는 실제 승률(%)이다. 승률 1%p 차이를 5점 또는 10점 차이로 보존한다. 50%를 중립점으로 둔 **연구용 스케일**이지 검증된 통계 추정량이 아니다. s=5는 40~60%, s=10은 45~55%에서 선형이며 그 밖은 포화한다. 두 기울기는 민감도 확인용이고 어느 쪽도 최종 정책으로 확정하지 않았다. 나머지 Qp/Qb는 그대로 유지해 승률 정규화 효과를 구분했다.

백분위의 과장 사례로 아시아 전체 등급 라마트라와 자리야의 승률 차이 0.1%p는 Qw에서 약 7.14점 차이가 된다. F5에서는 0.5점이다. 이런 인접 승률 차이 0.2%p 이하 사례가 입력에서 87쌍 발견됐다. 반대로 F5가 승률 점수의 분산을 줄이면 인기·밴 점수의 상대 영향이 커질 수 있다. 포화된 관측은 F5에서 3개, F10에서 59개여서 실제 차이를 무조건 더 잘 보존한다고 주장할 수 없다.

## 4. 밴률과 저승률 승격 진단

B20과 B15의 차이는 픽률 5%를 밴률로 옮기는 실험이다. 다른 입력·승률 계수는 동일하다.

`B20 - B15 = (Qb - Qp) / 18`

따라서 밴 백분위가 픽 백분위보다 높을수록 점수가 올라가며 최대 차이는 약 5.56점이다. 아시아 전체 파라는 A에서 6위/A, B15에서 7위/A, B20에서 4위/A다. B20의 제한 전 S는 픽 백분위 조건으로 A에 제한된다. 밴률 37.2%가 승률 52.7%·픽률 5.8%의 다른 지표보다 강한 역할을 한다.

아메리카 다이아몬드 프레야는 승률 49%, 픽률 4.5%, 밴률 20.7%이며 B15 대비 B20에서 3계단 상승한다(최종 17위/C). 이는 밴 계수가 저승률 영웅에게도 순위 이익을 주는 사례이지 실제로 과대평가되었다는 정답 검증은 아니다. 기피·불쾌감·특정 대응 난도 등 밴의 동기를 이 비율만으로 구별할 수 없다.

기존 S 조건을 그대로 적용하면:

- B20 아시아 마스터 둠피스트: 승률 49.7%, 픽률 10.7%, 밴률 31.3%, 3위/S 구간 → **A 제한**.
- B20 아시아 그랜드마스터 캐서디: 승률 49.3%, 픽률 35.2%, 밴률 18.9%, 4위/S 구간 → **A 제한**.
- 모든 비교 모델에서 승률 50% 미만 최종 S는 0개다. 그러나 순위 자체와 A 승격은 막지 않는다. 아시아 다이아몬드 캐서디의 C→A가 그 예다.

S 조건은 N≥5, 실제 승률≥50%, 픽률≥1%, 원래 Qw≥60, Qp≥40을 유지했다. raw 승률 모델에서도 Qw 자격 검사는 바꾸지 않았다. S 빈자리는 채우지 않았다. B20의 S 제한 사례는 총 10개로 A의 5개보다 늘었다.

밴률을 올리는 정책은 높은 활용도에도 좋은 성과를 유지하는지를 직접 측정하지 않는다. B20의 높은 승률(Qw≥75)·역할 내 평균 미만 활용도·Top3 사례는 A 21개에서 20개로만 줄어, 저채용 고승률 문제를 강하게 해소하지 못했다. F5는 이 사례를 11개로 줄이지만 저승률 Top3를 8개, 제한 전 저승률 S를 11개로 늘린다. 문제의 종류를 바꾸는 위험이 있다.

## 6. R 데이터 확보 가능성과 거부 조건

[OverFast 공개 OpenAPI](https://overfast-api.tekrop.fr/openapi.json)의 HeroStatsSummary는 hero/winrate/pickrate/banrate만 제공한다. 검토 스키마는 `data-availability.json`에 보존했다. 개별 플레이어 전적은 전체 영웅 모집단 성과가 아니므로 사용하지 않았다.

[블리자드 공식 통계](https://overwatch.blizzard.com/en-us/rates/)의 공개 지표 역시 현재 요구된 역할별 per10 성과를 제공하지 않는다. [Counterwatch 방법론](https://www.counterwatch.gg/methodology)은 동의한 앱 사용자의 매치 결과와 일부 per10 지표를 설명하지만, HOW 입력과 동일한 패치·지역·등급·집계 정의·표본 구성 및 재사용 허가가 확보된 집계 자료는 확인하지 못했다. 내부 API 호출·DB 복제·무단 수집을 하지 않았다.

현재의 8개 입력 자체도 정확한 집계 패치가 확인되지 않았다. 따라서 새로운 R 자료가 단순히 '다이아몬드'라고 표시돼 있어도 이 자료에 결합할 수 없다. C20/C15는 **432개 모두 미계산**이다. R을 0/50으로 채우거나 R이 빠진 식을 전체 v3로 표시하지 않았다.

연구 모듈의 R 검증 계약은 다음을 요구한다.

- rateContext와 성과 자료 양쪽의 패치 검증, PC/지역/등급/모드/전장/패치 일치.
- population='hero-aggregate', HTTPS 출처, 명시적으로 확인된 재사용 허가.
- 지표 정의 ID, per-10-minutes 또는 per-life 단위, 높을수록/낮을수록 유리한 방향, 역할 내 비교 가능성 검토.
- 역할별 세부 가중치의 명시적 입력. 기본 가중치는 없다.
- 해당 역할 전체 영웅의 유효한 성과값. 누락 지표는 0으로 만들거나 남은 지표로 재가중하지 않고 그 역할의 R 계산을 보류한다.
- 처치/목숨의 분모, 실제 영웅 사용시간과 경기시간의 차이, aggregate 비율 산출법을 원본 정의로 확인해야 한다. 플레이어 비율을 단순 평균하여 집계 성과를 만들면 안 된다. 제공처의 표본 구성이 다르면 같은 필터라는 이유만으로 비교 가능하다고 인정해서는 안 된다.

이 계약의 메타데이터 플래그는 외부 검토를 대신하지 않는다. 현재 승인된 performance 입력은 null이다. 단위 테스트의 명확히 표시된 합성 자료는 검증 코드 확인용이며 비교 CSV나 사용자 화면에 넣지 않았다.

## 7. 역할별 R 설계 후보와 편향

R의 각 세부 지표도 역할 내 백분위로 변환하고 데스는 100-Qdeath로 역전할 수 있다. 이는 가능성 검토이며 가중치는 채택하지 않았다.

| 역할 | 세부 후보 | 비교상의 주요 문제 |
|---|---|---|
| 공격 | 최종 타격/10분, 목숨당 처치, 데스/10분 역지표 | 마무리 확보와 넓은 처치 관여는 다른 개념. 포탑·지속 피해·폭발 피해·암살의 크레딧이 다름. 최종 타격과 처치/목숨은 중복 신호이고 데스는 두 번 반영될 수 있음 |
| 돌격 | 처치 관여/10분 또는 정의된 교전 관여, 데스 역지표, 피해 경감/10분 | 교전의 경계·관여 정의 필요. 방벽·흡수·방어력·자가 치유·위치 확보는 같은 방식으로 집계되지 않음. 불필요하게 피해를 받거나 방벽을 소모하는 행동에 점수를 줄 위험 |
| 지원 | 도움/10분, 치유/10분, 구조/10분, 데스 역지표 | 공격/수비 도움 크레딧·오라·자동 치유의 차이. 탱커 체력과 팀 조합에 따라 치유량이 달라짐. 구조는 고유 기술별로 측정법이 달라 모든 영웅에게 공통 비교가 가능한지 미확인 |

세부 가중치 후보는 다음처럼 여러 안을 사전 등록하고 나중에 같은 검증 자료에서 비교한다.

- 공격/돌격 3개 지표: 균등(1/3,1/3,1/3), 교전 성과 강조(1/2,1/4,1/4), 생존 강조(1/4,1/4,1/2). 돌격은 지표의 순서를 명시해 의미를 맞춰야 한다.
- 지원: 도움·치유·데스 3지표 안과, 구조가 실제로 공통 측정 가능할 때만 도움·치유·구조·데스 4지표 균등 안을 별도로 비교한다. 구조가 누락됐다고 4지표 모델에서 임의로 3지표로 바꾸지 않는다.

지금 이 안들에 실제 순위나 우수성을 부여할 수 없다. 피해 경감이나 치유의 원시량을 역할 간 직접 비교하지도 않는다. 같은 역할 안에서도 플레이스타일별 편향을 검증해야 한다. 하위 역할별 층화는 검증용 분석으로 검토할 수 있으나 소수 그룹을 별도 티어로 자동 분할하지 않는다.

### 중복 영향 검증 계획

현재 W/P/B의 역할·조건별 상관은 results.json에 기록했다. R이 없으므로 R-W 또는 R-P의 상관계수를 실제로 계산하지 않았다.

성과가 좋으면 생존·처치·승률이 함께 높아질 수 있고, 높은 채용 영웅은 팀 조합·숙련도·카운터 선택에 노출되는 양상이 다르다. R 10%가 독립 정보 10%를 뜻하지 않는다. 자료 확보 후 같은 역할·조건에서 지표 간 상관, R 제외/각 하위 지표 제외 ablation, 하위 역할별 잔차, 패치 분리 검증을 먼저 수행한다. 상관만 보고 승률을 원인으로 제거하거나 개인 경기 수를 추정하지 않는다.
