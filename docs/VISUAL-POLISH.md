# HOW Visual Polish 검증 기록

기존 정보 구조와 기능을 유지하면서 표면·타이포그래피·공통 컨트롤을 정돈했다. 로컬 수정과 검증만 수행했으며 Commit, Push, 배포는 하지 않았다.

## 원인과 적용 방향

화면별로 따로 정의한 네이비 색상, 테두리, 둥근 모서리와 제목 굵기가 누적되어 카드의 위계가 일정하지 않았다. 일부 분석 카드의 강한 상단 테두리와 따뜻한 배경도 핵심 수치와 강조를 경쟁했다. 이를 공통 토큰으로 연결하고, 오렌지는 선택·주요 행동·핵심 값에 집중했다.

| 구분 | 기준 |
| --- | --- |
| 배경 / 카드 / 안쪽 / 올림 표면 | `#10151e` / `#18222f` / `#131b27` / `#213044` |
| 주요 / 보조 텍스트 | `#edf2f8` / `#aab8ca` |
| 구분선 / 컨트롤 경계 | `#2b394b` / `#3b4b61` |
| 포인트 / 포커스 | `#f99e1a` / `#72b9f5` |
| 성공 / 주의 / 오류 | `#7ff5b6` / `#e7c77e` / `#ff9db0` |
| 컨트롤 / 카드 / 패널 모서리 | 8 / 12 / 14px |
| 간격 | 4 / 8 / 10 / 12 / 16 / 20 / 24 / 32px |
| 페이지 / 섹션 / 카드 / 본문 / 라벨 / 메타 / 수치 | 32 / 18 / 14 / 13 / 12 / 11 / 22px |

크기는 역할별 기본값이다. 기존 배너와 작은 화면의 밀도 조정 규칙은 유지했다. 모든 기존 크기를 일괄 치환하지 않았다.

## 화면별 변경

- 티어리스트·메타: 카드와 분석 패널의 표면·테두리 통일, 강한 상단 장식 완화, 표 수치 정렬과 보조 텍스트 대비 개선.
- 영웅 상세: 통계·패치·기술·특전 카드의 모서리와 제목 위계 정돈, 그래프 축과 설명 색상 통일. 그래프 데이터·애니메이션 코드는 변경하지 않았다.
- 전적 검색: 기존 HUD 배경·일러스트는 유지하고 입력창·결과 카드·빈 상태의 공통 표면과 포커스를 적용했다.
- 플레이어 상세: 요약 수치의 굵기와 크기, 전적 카드와 내부 분석 영역의 표면 차이를 정돈했다. 역할 필터와 별표 기능은 유지했다.
- 공통: 콤보박스의 기존 구조와 높이는 유지하고 색상·팝업 모서리·그림자를 토큰으로 연결했다. 전체 밝기 필터로 번쩍이는 hover를 제거하고 기존의 미세한 배경 변화와 이동을 유지했다. 키보드 포커스와 별표의 얇은 포커스 표시를 유지했다.

## 이번 단계에서 수정한 파일

- `src/styles/designTokens.css` — 의미별 디자인 토큰 추가
- `src/styles/visualPolish.css` — 최종 공통 표면·타이포그래피 스킨 추가
- `src/styles/main.css` — 기존 전역 변수와 새 토큰 연결
- `src/styles/filters.css` — 공통 콤보박스 색상·팝업 정돈
- `src/styles/player.css` — 플레이어 화면의 중립 색상을 토큰으로 연결
- `src/main.js` — 두 스타일시트 import 추가
- `scripts/qa-visual-polish.cjs` — 브라우저 회귀 검사와 캡처
- 이 문서와 `docs/qa/visual-polish/` 검증 자료

작업 전부터 존재했던 Phase 6 등 미커밋 변경은 보존했다. 계산·API·번역·라우팅·SEO 및 원본 JSON은 이번 단계에서 수정하지 않았다.

## 실제 Chrome 검증

320 / 390 / 430 / 768 / 1024 / 1280 / 1440px × 한국어·영어·일본어 21개 조합을 변경 전후 검사했다. 각 조합에서 티어리스트, 영웅 통계, 전장 비교, 기술, 특전, 메타픽, 검색, 검색 결과, 프로필, 영웅 분석의 10개 상태를 캡처했다.

- 문서 가로 넘침 0건, JavaScript 페이지 오류 0건.
- 변경 전후 영웅 목록의 순서와 전체 표시 텍스트 fingerprint 일치.
- 표 내부 가로 넘침 증가 없음. PC 표 행은 수치 글씨 정리로 약 1~2px 증가했다.
- 역할 필터, 키보드 선택·닫기, 승률·픽률·밴률 전환, 전장 비교와 이력 복원, 실제 저장된 특전 수치 표시 확인.
- 390 / 1440px 한국어에서 기존 실제 이미지 로딩 화면을 추가 캡처했다.
- 같은 두 너비에서 일반 모션으로 선→막대→선 애니메이션의 시작·중간·완료 상태와 실제 opacity/transform을 기록했다. 주 검사는 reduced-motion으로 수행했다.
- 로딩·검색 0건·503 오류·비공개 프로필은 별도 모의 응답으로 표시를 검증했다.
- 기본 보조 텍스트와 카드 표면의 대비는 7.96:1이다. 전체 요소에 대한 접근성 인증을 뜻하지 않는다.

## 참고와 남은 개선점

[OWTICS](https://owtics.gg/en-US/hero), [OWPerks](https://owperks.com/en)의 공개 콘텐츠 구분과 정보 위계만 참고했다. 외부 CSS·자산·레이아웃은 복제하지 않았다.

기존 정보 구조를 유지했으므로 PC 티어 표까지의 긴 상단 영역, 문맥상 작은 메타 라벨, 긴 설명에 따른 카드 높이 차이는 남아 있다. 향후 구조 변경이 승인되면 별도 개선할 수 있다. 기존 500kB 초과 JS 번들 경고도 이번 디자인 작업 범위에서는 변경하지 않았다.
