# 모바일 기술·특전 2열 UI

2026-11-10 로컬 변경. 기존 미커밋 모바일 메인 수정은 보존했다.

## 구현

768px 이하에서 `#detail-minor`, `#detail-major`, `#detail-abilities`, `#detail-unique-passives`의 그리드만 `repeat(2,minmax(0,1fr))`로 표시한다. 고유 지속 능력이 한 개면 전체 너비를 사용한다. 통계 탭의 하위 역할 지속 능력·카운터·시너지와 상단 배너/탭은 변경하지 않았다.

카드는 padding 10px, gap 8px, 아이콘 32px, 이름 13px, 설명 12px, 선택률 19px, 선택 건수 11px, 막대 6px다. 고정 높이 및 전체 화면 scale을 사용하지 않는다. 설명은 기존 compactText를 재사용해 두 줄 미리보기와 더보기/접기를 제공한다. 버튼은 44px 이상이며 aria-expanded를 갱신한다. 원문은 DOM에 보존하고 PC에서는 전체 설명을 표시한다. 선택률·건수·막대는 설명 접기와 독립적이다.

기존 영상 details와 원본 source·controls·preload=none을 유지했다. 영상은 처음에는 접혀 있고 열면 카드 안에서 표시된다. 기존 특전 Model/Service/OverLooker JSON과 매핑·계산은 변경하지 않았다.

## 검증 범위

Chrome headless, 320×700 / 360×780 / 375×812 / 390×844 / 430×932 / 768×900 / 1024×900 / 1440×900에서 정커퀸·겐지·아나·리퍼·에코의 기술/특전 탭 80개 조합을 검사했다. 기존 실제 API 응답 QA 파일과 운영 특전 JSON을 재생했으며 신규 통계 수집은 하지 않았다. 웹폰트는 차단하고 실제 기술/특전 아이콘은 디코딩 후 촬영했다.

각 조합에서 두 카드의 실제 X/Y 좌표, 카드 너비/높이, 선택률 문자열, 카드/문서 넘침을 기록했다. 모바일 2열, 설명 토글, 영상 펼침을 검사했다. 겐지 390px에서 원본 영상 재생에 성공했고 readyState=4를 확인했다. 특전 원본에서 영웅 항목이 빠진 불완전 응답을 별도 주입한 1건에서는 기존 검증이 오류/재시도 상태를 표시했고 0%를 만들지 않았다. 운영 JSON은 변경하지 않았다. 최종 브라우저 결과는 80개 정상 조합과 1개 오류 조합 총 81건이며 넘침 0건이다. PC 1024/1440px의 5명 기술·특전 카드 크기와 섹션 높이는 전후 모두 동일하다. 실제 iOS/Android 기기는 미검증이다.

218개 단위/회귀 테스트 통과. 기존 54명/216개 카드 매핑 검증은 유지했고 설명 원문·펼침 상태·선택률이 비동기 재렌더 및 탭 전환에서도 보존되는 테스트를 추가했다. build, verify:pages 및 diff 검사 통과.

- `scripts/qa-mobile-two-column.cjs`: 실제 브라우저 측정과 스크린샷.
- `docs/qa/mobile-two-column/`: 전후 결과 JSON, 스크린샷, 테스트 로그.
