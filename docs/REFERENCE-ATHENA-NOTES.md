# OW ATHENA 참고 메모

확인일: 2026-11-24. 공개 HTML과 개발자 안내를 확인했으며 HOW의 데이터 제공처·알고리즘은 변경하지 않았다.

## 확인한 정보 구조

- [영웅 목록](https://www.ow-athena.com/en/hero)은 공통 지역·등급 조건, 주요 메뉴, 목록/티어 보기, 역할·세부 역할 분류를 제공한다. 탐색 조건과 영웅 선택을 먼저 제시한다.
- [영웅 상세](https://www.ow-athena.com/en/hero/junker-queen)는 영웅 식별·역할, 점수/순위와 승률·픽률·밴률을 상단에 두고, 능력·특전·전장·추이를 뒤에 배치한다. 숫자 자체와 자체 분석 점수의 명칭을 구분한다. 열람 당시의 표본 수치는 HOW에 복사하지 않았다.
- [개발자 안내](https://www.ow-athena.com/en/dev-notes)는 pick/win/ban의 원천을 공식 Blizzard 데이터라고 밝힌다. adjusted pick, 자체 meta score, 전장 적합도 및 합산 점수를 별도 개념으로 설명한다. HOW의 Meta Score와 같은 공식이라는 근거는 없다.

## 출처에 관한 사실과 추정의 구분

[넥슨 공식 영웅 통계](https://overwatch.nexon.com/hero/rate)와 [Blizzard 공식 통계](https://overwatch.blizzard.com/ko-kr/rates/)가 존재한다. 그러나 ATHENA가 넥슨 페이지를 직접 수집한다는 경로·내부 API·갱신 주기는 공개 안내만으로 입증되지 않는다. '공식 Blizzard 데이터 기반'이라는 공개 설명과 '넥슨 페이지를 수집했을 가능성'이라는 추정은 다르다. 한국 데이터의 실제 수집 경로는 미확인으로 남긴다.

## HOW에 적용할 원칙

1. 조건 → 영웅/핵심 수치 → 비교·추이라는 정보 우선순위를 유지한다.
2. 원본 퍼센트와 HOW의 파생 점수·추천 티어를 구별한다.
3. 축 레이블은 장식보다 안정적인 여백·글자 크기를 우선한다.
4. 공통 프레임과 필터는 고정하고 화면 콘텐츠만 전환한다.

차용하지 않는 요소: ATHENA의 배치·색상·브랜딩·자산·점수 공식·세부 역할 명단의 복제. 이번 HOW 수정은 기존 CSS 토큰, SVG 로고와 기존 대시보드 구조를 사용한다. 레퍼런스의 상호작용과 시각적 모션은 실제 브라우저에서 검증하지 않았으므로 구현 사실로 단정하지 않는다.
