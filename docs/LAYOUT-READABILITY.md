# 티어표 중심 레이아웃 정리

2026-11-02. 기능 추가 없이 HTML 배치와 CSS만 조정했다. Model / View / Controller / Service / Domain 구현과 API·티어 공식은 변경하지 않았다.

## 배치

- PC(1100px 초과): 최대 1440px 컨테이너, 넓은 메인 컬럼 + 288px 인사이트 사이드바, 간격 24px.
- 메인 패널: 목록 제목 → 현재 조회 조건과 지역/등급/모드 → 역할·검색 → 결과 수·정렬 → 조회 상태 → 티어표 → 출처/조회 시각.
- 오른쪽: HOT → 숨은 꿀영웅 → 기존 메타 티어 선정 기준 → 승률/픽률/밴률 요약 → 즐겨찾기 → 개발 예정 안내.
- “메타 핵심 영웅”은 새로운 추천 알고리즘을 추가하지 않고 기존 티어 선정 기준 안내 카드로 정리했다. 실제 영웅의 티어·점수·산정 근거는 기존 목록/상세 기능으로 확인한다.
- 카드 패딩을 16px, 주요 제목을 15px, 대표 영웅 초상화를 PC 40px로 줄였다. 설명·미제공·출처 안내는 유지하고 긴 조회 조건 설명은 펼침 영역으로 옮겼다.
- 배너 높이를 PC 최소 350px, 모바일 최소 320px로 줄여 메인 콘텐츠에 더 빨리 도달하게 했다.

## 반응형 규칙

| 구간 | 메인 구조 | 영웅 목록 | 보조 정보 |
|---|---|---|---|
| PC >1100px | 2열 | 넓은 테이블 | 오른쪽 단일 컬럼 |
| 태블릿 601~1100px | 1열 | 테이블, 601~767px에서 셀 간격 축소 | 목록 다음, 카드 그리드 |
| 모바일 ≤600px | 1열 | 기존 영웅 카드 | 목록 다음, 단일 컬럼 |

390px 규칙: 좌우 바깥 여백 12px, 지역/등급 필터 2열, 역할 4버튼, 검색과 정렬은 각각 독립 행. 선택 UI는 16px, 터치 컨트롤 최소 높이 44px. 영웅 초상화는 72px, 카드 간격은 10px다. CSS로 시각적 순서만 뒤집지 않고 실제 DOM에서도 목록이 인사이트보다 먼저 나온다.

정렬은 기존 **기본 (HOW 티어순)**을 유지한다. S→A→B→C→D→미분류, 같은 티어에서 Meta Score 내림차순→이름순이다. Meta Score·승률·픽률·밴률·이름 정렬도 그대로 유지한다.

## 변경 파일

- `index.html`: 필터/제목을 메인 패널 안으로 이동, 인사이트를 사이드바로 이동, 설명의 펼침 구조 정리. 기존 이벤트/렌더링용 id와 data 속성 유지.
- `src/styles/layout.css`: 메인 페이지에 범위를 한정한 레이아웃·밀도·반응형 스타일. 상세 페이지의 스타일은 유지.
- `src/main.js`: 레이아웃 스타일 import 1줄 추가.
- 본 문서: 배치와 검증 범위 기록.

## 검증

- `npm.cmd test`: 기존 54/54 통과. 필터, 정렬 상태, 표/카드의 동일 순서, HOT/숨은 후보, 상세 보기, 즐겨찾기, 요청 경합 등 회귀 확인.
- DOM 점검: 중복 id 없음, 모든 기존 필터가 메인 패널에 있음, 지역→등급→역할→정렬→목록 순서, 목록→인사이트 순서 확인.
- `npm.cmd run build`: 프로덕션 빌드 통과.
- `npm.cmd run verify:pages`: /HOW/ 기준 로컬 자산 경로 확인 통과.
- 실제 브라우저 도구가 **No browser is available**을 반환했다. PC/태블릿/390px에서의 실제 픽셀 배치, 가로 오버플로, 잘림, 터치와 스크린샷은 검증하지 못했다. CSS 규칙 및 DOM 검증을 실제 브라우저 검증으로 간주하지 않는다.
- Model/Controller/Service/Domain 파일은 이번 작업에서 수정하지 않았다. GitHub Push와 공개 배포도 하지 않았다.
