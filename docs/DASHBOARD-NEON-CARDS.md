# 대시보드 네온 프레임과 카드 전체 슬라이드

2026-11-19. 기존 로컬 미커밋 작업 위에 후속 적용했다. Commit·Push·배포·자동화 활성화는 수행하지 않았다.

## 카드 디자인

- 역할 카드: 청록 외곽선 `#4a8796`, 더 어두운 내부 선, 네이비 명암 배경, 낮은 강도의 고정 그림자.
- HOT/주목 카드: 동일한 구조에 앰버 외곽선 `#a07843`과 주황 계열 내부 선·확산광.
- 내부 프레임은 카드에서 5px 안쪽의 1px 선이다. 하단 중앙에는 8px 원형 포인트와 작은 중심점을 배치했다. 장식은 포인터를 받지 않으며 보조 DOM은 aria-hidden이다.
- 장식은 CSS와 작은 span 하나로 구성했다. 외부 이미지·라이브러리·파티클을 추가하지 않았다. 텍스트 크기·통계 항목·바깥 간격은 유지했다.

## 전체 카드 전환

기존 내부 콘텐츠 전환을 고정된 **표시 슬롯 + 교체되는 article 카드**로 바꿨다. 카드 테두리·배경·내부 프레임·하단 장식·초상화·텍스트가 함께 움직인다.

- 이전 카드: `translateY(0 → -28px)`, opacity `1 → 0`.
- 다음 카드: `translateY(28px → 0)`, opacity `0 → 1`.
- 둘을 동시에 **520ms**, `cubic-bezier(0.22,1,0.36,1)`로 실행한다.
- 슬롯은 PC 128px, 1199px 이하 156px이다. 전환 중에도 문서 흐름과 인접 패널 위치는 변하지 않는다.
- 슬롯 경계에서 슬라이드를 잘라내고 낮은 강도의 글로우만 5px까지 허용한다. 기존 12px 간격 안에서 인접 카드와 광원이 겹치지 않도록 했다.
- 다음 세 카드의 이미지 디코딩이 준비되면 동시에 교체한다. 오래된 준비 작업은 기존 토큰으로 무효화한다. 이전 애니메이션·퇴장 카드는 취소·제거한다.
- 퇴장 카드는 aria-hidden/inert이며 활성 역할 식별자를 제거해 중복 읽기·클릭·잘못된 DOM 조회를 방지한다.

같은 영웅이 다음 지표에서도 1위이면 **전체 카드 슬라이드를 동일하게 유지**한다. 영웅이 같아도 지표가 바뀌었다는 사실을 일관되게 보여주기 위한 선택이다. 동일 이미지 URL은 기존 브라우저 캐시를 재사용한다.

표시 시간은 이전 정책 그대로 **전환 완료 후 5.5초**다. 실제 전환 시작 간격은 약 6.02초이다. 이미지 로딩 지연은 여기에 추가될 수 있다. 수동 지표 선택 버튼은 다시 추가하지 않았으며 일시 정지/재개 컨트롤과 지표 제목을 유지했다.

## HOT 모션과 성능

HOT 카드는 자동 슬라이드하지 않는다. 처음 표시되거나 실제 영웅·주요 표시값이 바뀔 때만 280ms의 약한 fade-up을 실행한다. 기존 9.2초 아우라와 7.2초 Meta Score 명암 흐름은 유지한다. Meta Score 값과 계산은 변경하지 않았다.

슬라이드는 카드당 transform/opacity만 애니메이션한다. 프레임·그림자는 정적이고 아우라는 고정 그림자 레이어의 opacity만 조절한다. 지속적인 will-change나 강제 레이아웃 측정은 추가하지 않았다. 통계 API·Meta Score·HOT·스냅샷·라우팅·공통 페이지 간격 정책은 변경하지 않았다.

Hover·Focus·문서 숨김에서 자동 순환을 정지한다. Reduced Motion에서는 슬라이드 없이 최종 카드로 교체하며 자동 순환·장식 모션을 정지한다. 실제 OS 백그라운드 탭 전환은 직접 검증하지 않았으며 visibilitychange 신호 회귀 테스트로 확인했다.

## 좁은 화면 보정

- 320px 영어 문구가 고정 높이를 넘는 경우를 실제 검증에서 발견했다. 역할 카드 패딩을 10→8px, 내부 세로 간격을 4→3px로 조정했다. 글자 크기는 줄이지 않았다.
- 기존 320px 헤더에서 언어 선택기가 정렬선을 넘는 문제를 발견해 해당 너비에서만 줄어들 수 있도록 했다. 언어 라벨은 한 줄 말줄임, 즐겨찾기는 한 줄을 유지한다. 접근성 이름·선택 기능·헤더/본문/푸터 패딩은 유지했다.
