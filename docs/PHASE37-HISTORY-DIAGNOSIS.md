# Phase 3.7 픽률 이력 표시 진단 및 보완

검토일: 2026-11-03. 로컬 최신 소스 기준이며 Push·배포·추가 수집은 수행하지 않았다.

## 코드 경로와 원인

`main.js`는 동일한 SnapshotService를 HOT와 상세 라우터에 전달한다. 상세 API 응답이 준비되면 routingController가 현재 조건으로 이력을 요청하고, HeroDetailView는 `#detail-page-statistics` 내부에서 `.detail-summary` 다음에 `#pick-history`를 생성한다. 카운터는 이 요약의 상단 오른쪽에 있으며, 이력 패널은 요약 다음·기술 탭 이전이다. 관련 CSS에는 패널을 숨기는 규칙이 없다. 상세 API 자체가 실패하면 상세 오류 화면으로 대체되므로 이력 패널도 생성되지 않는 기존 동작은 유지했다.

로컬 DOM에서 패널 자체가 누락되는 현상은 재현되지 않았다. 확인된 그래프 부재 원인은 기본 다이아몬드 조건의 관측 기록 0개이다. 기존 View는 0개에서 제목·버튼·빈 상태만 출력하고 SVG를 만들지 않는다. 전체 등급은 실제 기록이 1개이며 patch=null이므로 선 그래프가 아니라 관측점 하나만 표시된다. 기존 0–100% 축과 작은 점은 이 상황을 파악하기 어려웠다. 사용자가 본 화면이 로컬 최신 번들인지 여부 및 실제 화면에서 패널 자체가 없는 이유는 브라우저로 확인하지 못했다.

## 실제 데이터 (변경 없음)

- PC / 아시아 / 경쟁전 / 전체 등급 / 전체 전장: 1개.
- 기본 다이아몬드: 0개.
- 수집 시각: 2026-11-02T05:36:24.500Z (한국 14:36:24.500).
- 겐지 실제 관측 픽률: 13.6%, patch=null.
- 7일·30일 모두 이 기록이 범위 안에 있는 2026-11-03 기준으로 검증했다. 기간 밖이 되면 정상적으로 표시되지 않는다.

## 변경

- 빈 상태: 현재 조건·선택 기간의 관측 데이터 수집 전임을 안내한다.
- 단일 관측: 기록이 쌓이면 비교 가능하다고 안내한다.
- 패치 미상 관측: 검증된 패치 정보가 없어 선을 연결하지 않는다고 명시한다.
- 축은 실제 관측 범위에 여유를 주고 0–100% 안에서 확대한다. 표시 범위 너비는 최소 10%p로 제한한다. 최소·최대 및 확대 사실을 본문에 표시한다. 눈금은 5개이며 관측값은 반올림하지 않는다.
- 관측점 반경 4→6, 대비가 높은 테두리 및 선택 테두리를 적용한다. 테두리는 SVG 가로 축소와 무관한 두께로 표시한다. 단일 관측의 날짜는 한 번만 표시한다.
- 데이터·조건 매칭·연결 정책·HOT·티어·모바일 영웅 카드 CSS는 변경하지 않았다.
