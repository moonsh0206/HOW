# 플레이어 역할 필터 및 UI 통일

## 역할 필터

영웅별 경쟁전 기록 제목 오른쪽에 전체 역할(all)/돌격(tank)/공격(damage)/지원(support)을 추가했다. `createFilterCombobox()`와 `roleIcon()`을 그대로 사용한다. 새 드롭다운 또는 외부 라이브러리는 없다.

Controller의 `heroRole`이 선택값을 관리한다. 동일 playerId의 데이터 갱신·언어 전환·즐겨찾기 갱신에는 유지하고, 다른 playerId와 검색 초기화에서는 all로 되돌린다. 컨트롤 DOM은 View당 한 번만 만들고 재사용한다. 공통 컴포넌트에 선택적으로 호출할 수 있는 destroy를 추가하여 teardown 시 외부 클릭/언어 이벤트를 정리한다. 기존 다른 필터의 디자인이나 키보드 처리는 변경하지 않았다.

`topPlayerHeroes(stats, heroes, role)`는 기존 heroKey로 영웅 메타데이터의 role을 연결한다. 이름으로 추측하지 않는다. 미확인 역할은 all에서만 보인다. 원본·승률·승패·KDA·전체 경쟁전 요약은 변경하지 않는다. 필터는 영웅 기록 목록에만 적용한다.

선택 역할을 먼저 필터링한 뒤 같은 시간순/동률 정렬을 유지하고, 그 역할의 최장 시간으로 나눠 막대를 계산한다:

`hero.seconds / maximumSecondsInSelectedRole × 100`

누락 시간은 막대 미제공이다. 유효한 양수 최대값이 없으면 막대를 만들지 않는다. 실제 0은 기존 정책을 유지한다. 비교 기준을 안내 문구와 기존 meter 접근성 정보로 표시한다. 표시 가능한 해당 역할 기록이 없으면 전용 안내를 제공한다.

역할 변경 시 계속 표시되는 영웅의 상세 펼침은 유지한다. 필터 밖으로 제외된 영웅은 닫히며, 다시 표시할 때 기본 접힘이다. 프로필·등급·즐겨찾기 데이터는 초기화하지 않고 API를 재요청하지 않는다. 배경은 전체 경쟁전 최다 플레이 영웅 기준의 기존 기능을 유지한다.

## UI 통일

- 검색 입력: 메인 검색의 네이비 배경·테두리·hover·focus 색을 적용, 16px 입력 폰트와 48px 터치 높이 유지.
- 검색 제목: 과도한 크기를 줄이고 설명 간격 정리. 배경 radial/HUD 장식과 기존 Empty State PNG는 그대로다.
- 검색 결과/즐겨찾기 카드: 이미 공통 panel/line 및 44px 별표를 사용하므로 레이아웃을 유지했다.
- 더 보기/재시도: 기존 기능을 유지하며 모서리를 8px로 맞춤. 오류 색은 메인 통계 경고와 같은 계열로 통일.
- 프로필 별표: 검색 카드와 같이 투명 배경, 선택 시 별표만 강조, 얇은 focus-visible 유지.
- 등급 카드: 공통 line 테두리와 어두운 반투명 배경. 원래 배경·티어 이미지는 보존.
- 요약 카드: 공통 panel 배경, 값 블록의 수직 정렬 통일. 승률 아래 승패는 유지.
- 영웅 목록: 기존 모바일 행 높이를 유지하고, 768px에서는 가로 공간을 활용해 한 줄 통계 행으로 전환.
- 메인 모바일 필터의 기존 반응형 CSS 규칙에 역할 필터 선택자만 추가했다. 코어 스타일 복제 없이 44px/16px, 일본어의 기존 글씨 크기 보정을 공유한다.

- `src/models/playerModel.js`: 역할별 파생 목록·시간 기준.
- `src/controllers/playerSearchController.js`: 역할 선택 상태와 change 이벤트, 정리.

- `src/styles/player.css`, `src/styles/navigation.css`: 플레이어 UI 정리 및 기존 반응형 규칙 공유.

기존 Phase 6 파일과 미커밋 작업은 보존했다. Provider·API 캐시/재시도·승패·KDA 계산·라우팅·SEO·영웅 메타/스냅샷은 변경하지 않았다.

## 검증

- 전체 회귀 테스트 **330개 통과**.
- 프로덕션 빌드 통과, 지역화 공개 HTML 660개. 기존 500kB 번들 경고는 남아 있다.
- Pages `/HOW/` 자산 15개 검증 통과. staged/unstaged diff 검사 통과.
- 실제 Chrome 320/390/430/768/1024/1280/1440 × KO/EN/JA **21조합 통과**: 네 역할, 빈 역할, 역할별 100% 기준, 중복 컨트롤 없음, 언어·즐겨찾기 유지, 가로 넘침 없음, 팝업 viewport 경계.
- 21개 기록에서 메인/플레이어 콤보박스의 배경색·테두리색·radius·글자색·글씨 크기·최소 높이·좌우 padding **8개 계산 CSS 값이 모두 일치**했다.
- 추가 390/1440 한국어 Chrome에서 기존 이미지 실로딩, Space/방향키/Enter 선택·Escape·Tab·외부 클릭 닫힘 확인. 선택 상태별 PNG와 기존 Empty State·API 오류 구분도 캡처했다.
- 실제 수집한 TeKrop 응답을 재생한 브라우저 검사다. 새 실시간 API 수집을 수행한 것은 아니다. 기본 검색/summary/competitive 3개 mock 요청이며 역할 변경·상세 열기·언어 전환에 추가 플레이어 API 요청은 **0회**였다. 빈 검색/503 화면 검증은 명시적 테스트 fixture다.
- 미확인 역할·동일 플레이어 새로 조회/캐시·다른 playerId 초기화·제외된 상세 패널·원본 불변·키보드·teardown은 단위/기존 회귀 테스트로 검증했다. 429/타임아웃/503/504는 기존 모의 API 테스트를 유지했다.

역할 컨트롤 추가로 모바일 목록 시작은 약 24px, PC/태블릿은 약 16px 내려간다. 모바일 행과 가독성을 유지했으며, 태블릿 행 높이는 약 40% 감소했다. 조회된 역할에 따라 표시 목록 길이는 줄어든다. 높이는 언어/데이터에 따라 달라진다.

## 증거와 제약

- 전후: `docs/qa/player-role-ui/{before,after}/results.json`, 검색/개요/펼침/role-open PNG.
- 이미지 포함 역할별 화면: `docs/qa/player-role-ui/after-images/{390,1440}-ko-{tank,damage,support}.png`.
- 개인 전적만 사용한다. 티어 평균·추정 백분위·가상 통계는 추가하지 않았다. 전체 영웅/플레이어를 실서비스에서 전수 조회한 것은 아니다.
- Commit/Push/배포 없음.
