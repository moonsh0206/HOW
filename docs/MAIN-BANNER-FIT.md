# 메인 배너 원본 구도 보존

2026-11-09. 변경 범위는 `src/styles/main.css`, `src/styles/layout.css`의 메인 배너 표시 규칙뿐이다. 별도 QA 스크립트/스크린샷을 추가했다. 로고, HTML 문구/CTA, 상세 페이지, 필터 및 통계 코드는 변경하지 않았다.

## 원인 및 수정

원본 `hero-banner.jpg`는 5760×2400(12:5)이다. 모바일의 `cover`는 좁은 배너에 맞추면서 좌우 영웅을 잘라냈으며, 1500px 이상에는 추가 135% 확대 규칙이 있었다.

이미지 자체는 그대로 두고 `contain`/`no-repeat`으로 전체 구도를 보존한다. PC는 오른쪽 이미지 레이어를 원본 비율로 배치하고 왼쪽 가장자리를 네이비 그라데이션 마스크로 연결한다. 모바일은 전체 너비×5/12 높이의 이미지 레이어를 상단에 두고, 하단 60px 구간을 네이비로 연결한다. 텍스트는 이미지 마지막 16px 구간부터 시작해 주요 얼굴과 겹치지 않도록 한다. 새로운 이미지, 화면 확대/축소 또는 원본 비율 왜곡은 없다.

가로 원본 전체를 보존하면서 글자 크기와 CTA를 유지하려면 모바일 높이가 일부 늘어나는 것이 불가피하다. 불필요한 빈 블록이나 고정 최소 높이 대신 실제 이미지 비율과 기존 텍스트 높이를 사용했다.

## 실제 검증

Chrome headless + Vite production preview `/HOW/`에서 위 9개 너비를 확인했다. 로컬 SVG/JPG를 실제 로딩하고 외부 API는 차단해 배너 검증에 집중했다. 따라서 스크린샷 하단 통계 오류 안내는 QA 네트워크 격리 결과이며 기능 수정 결과가 아니다.

모든 너비에서 로고 로딩·원본 비율·홈 링크·문서 가로 넘침 0 확인. PC/모바일 동일 원본 구도, 그라데이션 연결, 헤드라인 가독성과 CTA 노출을 스크린샷으로 확인했다. 768px 이상은 기존 텍스트 오버레이를 유지하므로 이미지 일부는 어둡게 표현된다. 기하학적으로 원본이 크롭되는 것과는 구별된다. 실제 휴대폰/Safari는 미검증이다.
