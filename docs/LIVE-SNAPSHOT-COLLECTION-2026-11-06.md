## 실행과 저장

최신 collect-division-batch.js의 명시적 수동 실행을 사용했다. 적응형 패치 일정은 effectiveAt이 미확인이라 자동 목표 시점으로 실행할 수 없지만, 이번에는 사용자가 승인한 일반 관측 수집이다. 패치 귀속을 만들거나 D+1 등으로 재분류하지 않았다.

```sh
node scripts/collect-division-batch.js --region asia --apply
node scripts/collect-division-batch.js --region europe --apply
node scripts/collect-division-batch.js --region americas --apply
```

아시아 저장·복원을 확인한 후 나머지 지역을 순차 실행했다. 27개 고유 원본 코호트를 한 번씩 요청했고 자동 재시도는 없었다. 429/503, 타임아웃, 실패 등급은 없었다. 원본은 PC/경쟁전/전체 전장 및 지역별 all, bronze, silver, gold, platinum, emerald, diamond, master, grandmaster다.

| 지역 | 실제 신규 파일 (public/data/snapshots/) | 원본 성공 | 파생 복원 | 영웅/등급 |
|---|---|---:|---:|---:|
| 아시아 | 2026-11-06T02-37-44.293Z.json | 9/9 | 7/7 | 54 |
| 유럽 | 2026-11-06T02-38-15.758Z.json | 9/9 | 7/7 | 54 |

파일명 시각은 UTC 저장 파일 생성 시각이다. 각 등급의 실제 HOW 조회 시각은 divisions의 collectedAt에 별도로 기록된다. 아시아는 약 11:37 KST, 유럽·아메리카는 약 11:38 KST에 수집됐다.

index.json에는 기존 2개 항목을 그대로 두고 **27개 원본 항목을 추가해 총 29개**가 됐다. 고유 데이터 파일은 기존 v1 2개 + 신규 v2 3개 = 5개다. 각 v2의 derived는 동일 파일 내부에 저장하며 인덱스에 평균 등급을 중복 원본처럼 등록하지 않았다.

## 수치·품질·평균 검증

- 원본: 27개 코호트 × 54명 = **1,458개 영웅·조건 기록**, 승률/픽률/밴률 **4,374개 지표** 저장.
- 파생: 지역당 bronze_plus, silver_plus, gold_plus, platinum_plus, emerald_plus, diamond_plus, master_plus 7개. 전체 **3,402개 파생 지표**를 구성 원본에서 별도로 산술평균해 비교했다.
- 현재 원본 27개 모두 54명·고유 key·세 지표·0~100 범위를 통과했다. HOW 품질 정책상 null/결측/검토 대상은 이번 배치에서 모두 0명이다. 이는 API 원본 집계의 통계적 신뢰성을 별도 검증했다는 뜻은 아니다.
- 원본·파생 전체 **48개 프레임** 복원에 성공했다. 동일 지역·모드·플랫폼·전장·배치와 최대 5분 관측 허용 차이를 유지했다.
- 캐시 Age가 제공된 응답은 해당 초 값을 기록했다. 헤더가 없었던 16개 응답은 null이며 0으로 만들어 넣지 않았다. 제공된 Age는 688~3,524초 범위였다. Age는 서버 응답 캐시의 나이로, 원본 경기 집계 마감 시각이 아니다.
- 모든 patch는 null, patchVerification.status는 unverified다. 원본 집계 시각/패치 시작 집계창은 확인되지 않았으므로 확정 대표점이 아니다.

## 그래프와 HOT

실제 로컬 index와 JSON만 읽는 SnapshotService로 3지역 × 16등급의 조회를 확인했다. 각 조건에서 승률·픽률·밴률을 전환해 겐지 관측값이 실제 파일 값과 일치하고, jsdom SVG에 해당 관측점 개수가 그려지는지 **144개 지표 렌더링**을 확인했다. API를 추가 호출하지 않았다. 파일 캐시 때문에 실제 읽기는 index 1회와 데이터 파일 5회였다.

| 조건 | 저장 관측 | 이전 HOT 비교 |
|---|---:|---|
| 아시아 전체 등급 | 2개 (11/02, 11/06) | 동일 조건의 실제 이전 관측 조회 성공 |
| 아시아 다이아몬드 | 2개 (11/04, 11/06) | 동일 조건의 실제 이전 관측 조회 성공 |
| 아시아 diamond_plus/master_plus 및 다른 단일·누적 등급 | 각각 1개 | 이전 동일 조건이 없어 HOT 미제공 |
| 유럽·아메리카의 각 단일·누적 등급 | 각각 1개 | 이전 동일 조건이 없어 HOT 미제공 |

기존 HOT 정책으로 아시아 전체 등급에서 키리코/정커퀸/브리기테, 다이아몬드에서 키리코/정커퀸/일리아리가 후보로 계산됐다. 선택 근거인 실제 %p 변화량은 JSON 보고서에 있다. 집계창은 미확인이라 패치 효과나 독립 경기 표본의 변화라고 해석하지 않는다.

기본 diamond_plus는 그대로다. 전체 등급/단일 다이아몬드의 기존 기록을 누적 평균의 과거값으로 사용하지 않았다. 현재 조회점은 stored:false라는 별도 상태로 취급하며 같은 수집 시각·값과 겹치면 저장 관측과 합쳐 중복 점을 만들지 않는다. 없는 과거 날짜·보간값은 생성하지 않았다.

이 검증은 실제 저장 파일 기반 모델/서비스/DOM 검사다. 실제 사용자 브라우저의 시각 검증과 새 브라우저 API/CORS 테스트는 수행하지 않았다.
