# 세 가지 메인 메뉴와 모바일 탐색 개선

2026-11-09. 최신 로컬 코드/미커밋 자동화 작업을 유지하고 화면/라우팅만 재구성했다.

## 화면과 경로

- `#/tiers`: 기본 화면. 기존 영웅 표/카드, 필터/검색/역할/정렬/즐겨찾기를 유지한다.
- `#/meta`: 현재 메타픽. 기존 HOT/숨은 꿀영웅/승률/픽률/밴률 상위 5개 영역을 같은 InsightView와 같은 모델로 제공한다. 조회 조건과 전체 역할 기준을 표시한다. 부족한 데이터의 설명도 기존대로 유지한다.
- `#/player-search`: 독립 PlayerSearchView의 개발 예정 화면. 입력/API/가상 플레이어 결과 없음.
- `#heroes`, `#favorites`, `#/`, 빈 해시와 기존 `#/heroes/{key}` 및 상세 하위 탭도 계속 동작한다.

로고 아래에 3개 실제 링크를 배치하고 현재 메뉴에 aria-current와 오렌지 강조선을 적용했다. 헤더의 중복된 티어 링크/검색 예정 표시는 제거하고 즐겨찾기 접근은 헤더에 유지했다. 로고 SVG와 홈 링크는 그대로다.

모바일 티어리스트 순서는 헤더 → 메뉴 → 배너 → 조회 조건/필터 → 최신 패치 요약 → 검색/역할/정렬 → 영웅 목록이다. 인사이트 전체가 목록을 밀어내지 않는다. 기존 즐겨찾기 미리보기는 목록 하단으로 옮겼으며 헤더에서 즉시 즐겨찾기 목록에 접근할 수 있다.

현재 메타픽은 PC에서 HOT/숨은 영웅 2열과 나머지 3열, 모바일은 1~2열로 표시한다. 원래 역할별 대표 후보와 설명/펼치기 기능을 유지한다. 픽률을 임의의 표본이나 신뢰도로 바꾸지 않는다.

패치 카드는 **하나의 DOM 노드**만 사용한다. 모바일 티어 화면에는 날짜+짧은 요약을 먼저 보이고 상세를 펼친다. 현재 메타픽에서는 같은 노드를 해당 화면으로 이동한다. 데이터/공식 링크를 중복 하드코딩하지 않는다.

## 상태와 성능

메뉴마다 모델이나 서비스를 만들지 않는다. 영웅 모델, 통계 서비스/캐시, InsightView, 패치 모델은 기존 인스턴스를 공유한다. 통계 필터 DOM도 한 개이며 티어/메타/상세의 host 사이를 이동한다. 모든 기존 값과 이벤트 경로를 유지한다.

메뉴 전환 때 검색/역할/정렬/통계 조건을 보존한다. 즐겨찾기 북마크는 기존의 즐겨찾기 전용 목록 전환 규칙을 유지한다. 영웅 상세는 진입한 티어/메타 경로로 돌아가는 링크를 제공하며, 브라우저 뒤로 가기의 메인 스크롤 위치를 현재 방문 범위에서 복원한다. 새로고침은 URL의 메뉴와 기존 저장 필터를 복원한다. 전체 페이지 새로고침 뒤의 과거 스크롤 저장까지 별도로 영구 보존하지는 않는다.

기존 상세 로딩 generation 검증을 새 메뉴에서도 적용하므로 상세의 늦은 응답이 메뉴를 덮어쓰지 않는다. 지연된 스크롤 복원 콜백도 다른 페이지로 이동한 뒤에는 적용하지 않는다.

## 모바일 배너와 도달 거리

원본 hero-banner.jpg는 변경하지 않았다. 모바일은 원본 비율을 보존한 contain 이미지와 기존 계열의 어두운 오버레이를 사용하고, 문구/CTA의 글자·여백을 조정했다. 전체 문구와 CTA는 유지한다. 320~430px에서 배너 높이는 약 **160.8px**다.

문서 맨 위에서 첫 영웅 카드까지의 실제 위치(Chrome 1000px 높이, 같은 저장 데이터):

|너비|이전|변경 후|단축|
|---:|---:|---:|---:|
|320|1759px|1011px|747px|
|360|1747px|1006px|741px|
|375|1680px|1006px|674px|
|390|1689px|1006px|683px|

텍스트/데이터 상태에 따라 높이는 달라질 수 있다. 768px 이전 측정에서는 숨은 표 행을 잡아 0으로 나온 값이 있어 그 너비의 전후 수치 비교에는 사용하지 않았다. 최종 검증은 실제 표시된 표 행 또는 카드를 선택한다.

## 실제 검증

Chrome production preview `/HOW/`, **320/360/375/390/430/768/1024/1440px**에서 다음을 확인했다.

- 한 줄 메뉴 3개와 44px 이상 터치 영역, 선택 상태, 기본 티어 진입.
- 티어/메타/개발 예정 메뉴, 새로고침과 뒤로/앞으로 가기.
- 메타 영웅 링크 → 상세 → 뒤로 가기와 스크롤 복원.
- 기존 즐겨찾기 북마크/저장/해제, 검색/역할/정렬.
- 현재 메타픽 5개 카드와 단일 필터/패치 노드.
- 390px에서 메타 화면의 지역 필터 변경과 복귀.
- 메뉴만 전환할 때 **추가 통계 API 요청 0**, 페이지 가로 넘침 0, 브라우저 실행 오류 0.

실제 저장된 통계/상세 응답 및 production 특전/패치 JSON을 이용한 격리 네트워크 재현이다. 제공처 실시간 성능이나 실제 휴대폰/Safari까지 검증한 것은 아니다. 일부 외부 초상화는 로딩 중 폴백이 보일 수 있다.

`npm.cmd test`: **212개 통과**, build/verify:pages(자산 12개)/git diff --check 통과. 신규 테스트는 경로 호환, 모델/필터/노드 공유, 상태 보존, 늦은 응답 차단과 서비스 호출 횟수를 검증한다.

## 남은 사항

전적 검색은 Phase 4에서 실제 제공처·오류·공개 프로필 정책을 구현해야 한다. 모바일 첫 카드 위치는 줄었지만 통계 조건·검색·정렬 및 품질 안내를 유지하므로 높이가 낮은 화면에서는 여전히 스크롤이 필요하다. 긴 데이터 없음/오류 안내나 패치 내용을 펼치면 목록 위치가 더 내려갈 수 있다.
