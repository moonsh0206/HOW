## 화면 구성

하나의 `.detail-summary` 안에서 `.detail-summary-main`과 `.detail-summary-side`를 1.65:1(약 62:38)로 배치한다. 왼쪽은 통계 4개 → 선택 지표 그래프 → 메타 점수·즐겨찾기·접힌 통계 정보이다. 오른쪽은 카운터 → 하위 역할 지속 능력이다. 카운터의 기존 링크·펼침 설명·데이터는 유지한다.

700px 이하에서 두 영역을 세로로 배치하므로 요청한 600px 이하에도 적용된다. 통계 → 그래프 → 간결한 메타/즐겨찾기 → 카운터 → 하위 역할 순서이다. 중복 목록 링크와 반복 조건 설명은 제거하고 조건·출처·HOW 조회 시각은 '통계 정보 ⓘ' disclosure에 보존한다. 상단의 원래 영웅 목록 돌아가기 링크는 유지한다. 긴 그래프 안내는 추가하지 않는다.

하위 역할은 `#detail-passives` 하나로 카운터 바로 아래에 생성한다. 아래 기술/특전 영역에 같은 내용을 반복하지 않는다. 별도 확인된 고유 지속 능력 슬롯은 `#detail-unique-passives`로 분리하여 보존한다. 현재 고유 패시브를 이름이나 순서로 임의 분류하지 않는다.

## 공통 시계열

- `buildMetricHistory` / `withCurrentMetricHistory`는 winRate·pickRate·banRate만 허용한다. 기존 픽률 호출과 테스트를 위한 함수 이름도 유지한다.
- 점은 공통 `value` 및 선택 지표 값을 보유한다. 스냅샷의 해당 필드만 추출하며 null은 0으로 대체하지 않는다. 같은 영웅·완전한 5개 조건 일치, 유효 날짜·0~100 검증, 중복 시각·누락·패치 미상·패치 경계·24시간 초과 연결 금지는 유지한다.
- 현재 통계도 원래 fetchedAt을 사용한다. 캐시 재사용으로 새 시각을 생성하지 않는다. HOW 조회 시각은 원본 경기 집계 마감 시각이 아니다. 현재 값은 실제 API 결과일 때만 추가하며 패치가 확인되지 않은 점 사이에는 선을 만들지 않는다.
- Controller는 조회한 원본 전체 영웅 스냅샷을 현재 상세 상태에 보관한다. 지표 전환은 메모리에서 다시 계산하고 같은 이력 요청을 재호출하지 않는다. 영웅/조건/기간 변경은 기존 요청 서명·경합 방지 정책에 따른다.
- 기본 지표는 픽률이다. 같은 영웅에서 기간·필터·일반 재렌더는 선택 지표를 유지한다. 다른 영웅으로 이동하면 픽률로 초기화하며 기간 7일/30일은 유지한다. 이전 영웅의 응답은 generation 검사로 무시한다.
- 승률·픽률·밴률은 native button으로 클릭·키보드 조작 가능하며 aria-pressed·aria-controls와 포커스 복원을 적용한다. 티어는 전환 대상이 아니다. 제목·현재 값·축·관측값·툴팁·접근성 레이블·스크린리더용 표가 함께 변경된다.

## 개시자 현재 효과 검토

[공식 2026년 5월 패치](https://overwatch.blizzard.com/ko-kr/news/patch-notes/live/2026/05/)에서 개시자가 공중 체류 대신 지정 기술로 발동하고 치유량이 60→50으로 바뀐 것을 확인했다. 둠피스트는 로켓 펀치가 발동 기술이다. 공통 효과에 치유량 50을 보존하고 둠피스트 설명에 로켓 펀치를 명시했다.

확인 가능한 6·7·8·9·10·11월 공식 월별 페이지에서 개시자 효과의 추가 변경은 찾지 못했다. 이는 모든 패치가 완벽하게 색인되었다는 보장이 아니며, 새 패치에 따라 재검토해야 한다. 공식 현재 영웅 페이지의 일반 효과 설명과 상충하지 않는다. 검토 URL과 확인 결과는 `research/subroles/initiator-review.json`에 저장했다. 6v6·스타디움의 개별 기술 변경을 개시자 효과로 추정하지 않았다.
