## 실제 데이터 출처와 검증

실제 [공식 페이지](https://overwatch.nexon.com/hero/rate)에서 선택한 필터의 URL을 공개 문서로 1회 조회했다. 반환 HTML의 Nuxt 공개 참조 테이블 중 `hero-rate-list`와 `hero-rate-filters`만 해석한다. 별도 비공개 API를 추측하거나 인증 정보를 재사용하지 않는다.

수집 시각은 **2026-11-24 12:07:20 KST**이며 원천 기준 시각이 아니다. `sourceUpdatedAt:null`. 원천 데이터 기준 시각·집계 기간·표본 분모가 없으므로 현재 시즌·당일 집계·경기 수를 추정하지 않는다.

- 영웅 54명: 돌격 15 / 공격 23 / 지원 16.
- 실제 heroId와 HOW fixture key 직접 대응: 54/54. 미매핑/누락/중복/역할 충돌 0.
- 승률·픽률·밴률 각각 54/54 화면 표시와 일치: 총 162개 값.
- 예: 겐지 승률 52.9%, 픽률 25.7%, 밴률 1.6%; 아나 49.7%, 58.7%, 10.1%.
- 바티스트의 실제 밴률 0.0%도 보존했다. null을 0으로 채우지 않는다.
- 이 조건에는 밴률이 실제 존재한다. 빠른 대전 payload의 밴률 0은 화면에서 미제공인 지표이므로 동일하게 취급하면 안 된다.
- HTML payload와 같은 페이지 DOM의 일치 검증이다. 독립적인 별도 데이터 제공처와 비교한 검증은 아니다.
- 원본 정밀도는 유지하고 공식 표시의 소수점 첫째 자리와 대조했다. 표시 반올림 오차를 원본 수정으로 보정하지 않는다.

실제 수치 12명 표와 필터 상세는 [조사 문서](NEXON-KOREA-DATA-RESEARCH.md)에 있다. 전체 최소 통계·검증 결과·원천 화면은 Git 제외 `.artifacts/nexon-korea/{trial.json,verified.json,trial.png}`에 보관한다. 운영 JSON에 반영하지 않았다.

## 지원 범위와 HOW 호환성

한국은 Nexon 원천 `korea`, HOW 후보는 `kr`로 분리한다. 기존 `asia/europe/americas` 키와 충돌하지 않는다. 시험 정규화 파일에만 `provider:nexon-korea`/`region:kr`를 기록하며 앱의 `validateFilters`나 지역 목록은 수정하지 않았다.

현재 공식 목록에는 빠른 대전 역할 고정(`rq=0`), 경쟁전 역할 고정(`rq=2`)만 있다. 한국은 PC만 선택 가능하다. 경쟁전 개별 등급은 bronze/silver/gold/platinum/emerald/diamond/master/grandmaster 및 all이며 grandmaster는 챔피언을 포함하는 단일 옵션이다. 다른 등급과 전장 조합은 목록 존재만 확인했으며 실제 모든 응답을 시험하지 않았다.

31개 개별 전장 key는 HOW `standardMaps.json`과 양방향 모두 일치한다. 유형 옵션은 맵이 아니므로 제외한다. 계절별 경쟁전 로테이션은 여전히 미확인이다. 추천 전장 TOP 3 연결 가능성은 있지만 한국 개별 맵 실제 통계·관측 호환성·권한 확인 전 연결하지 않는다.

상위 누적 등급은 공식 옵션이 없고 분모가 불명확하므로 현재 HOW 등급 균등 평균을 한국 공식 통합 지표로 표시할 수 없다. 제공처별 분리 정책 검토가 필요하다. 실제 연동 시 unsupported 필터를 OverFast로 보내거나 Asia로 조용히 대체해서는 안 된다.

현재 시험 조건에는 세 Meta Score 입력 지표가 있지만 제공처별 정의·집계 호환과 이용 조건이 미확인이다. 앱의 Meta Score/티어 계산에는 사용하지 않았다. 나중에 밴률 미제공 조건을 연동할 경우 산정 불가를 표시하고 0 대입·타지역 대체·임의 가중치 조정을 금지한다.

## 이용 조건 및 필요한 확인

[일반 이용약관](https://member.nexon.com/policy/policywrapper.aspx?date=20240322&policytype=31) 제11조 제1항 제4호와 제17조를 확인했다. 공개 조회 성공을 자동 수집·캐시·재배포 허가로 간주할 수 없다. 팬사이트의 정기 수집, 보관 기간, 파생 계산, 공개 JSON/화면 재게시, 출처 표기, 허용 빈도를 제공처에 확인해야 한다. 문의 발송·로그인·약관 동의는 수행하지 않았다.

사용자에게 전달된 공개 Open API 미제공 답변은 API 허가와 다른 사실이다. 사용자 작업 승인만으로 제공처의 재게시 허가가 확보되는 것도 아니다. 따라서 현재 사이트에는 한국 옵션을 노출하지 않는다.

## 자동화 후속 설계 — 미구현

권한과 모든 선택 조건의 정합성이 확인되면 다음 순서로 구현한다.

1. 제공처/지역/플랫폼/역할 고정 모드/등급/전장/schema를 묶은 독립 키와 이전 성공 기록 사용.
2. 허용된 공개 전달 경로로 조건별 순차 수집. 하루 1회 단일 cohort부터 시작하고 대규모 등급×전장 조합은 별도 호출 예산 승인.
3. 구조·범위·매핑·필터·관측 시점 검증. 오류·인증 요구·429/503에서 중단, 제한된 재시도/Retry-After 적용. 현재 시험기는 자동 재시도하지 않음.
4. 동일 조건/동일 원문 해시 중복 차단, 임시 후보 검증 후 원자적 교체. 실패하면 기존 정상 파일 보존. 현재 시험 결과는 운영 게시 후보가 아님.
5. 별도 source/schema 정적 파일을 빌드에 포함하고 기존 Pages 직렬화·복원 규칙과 연결. artifact 저장만으로 게시 성공 처리하지 않음.
6. 사용자 배포 승인 후에만 공개 JSON digest·관측 시각 확인까지 실행. 스케줄 활성화·운영 수동 실행은 별도 승인.

현재 시험 수집기는 범위가 고정된 단발성 검증 도구이며 운영 수집기의 재시도·원자적 게시·보존 기능을 구현했다고 주장하지 않는다.

## 검증 결과

- 실제 시험: 54명/162개 값 일치. 저장된 trial 재검증 성공.
- 중복 수집: 기존 파일이 있어 요청 전에 거부하는 것을 확인. 실제 수집을 다시 수행하지 않음.
- 단위/전체 회귀: **418/418 통과**. 정밀도/0/null/필터 오류/중복·미매핑·누락 영웅/비정상 비율/화면 불일치/참조 구조 변경·순환을 포함.
- 프로덕션: Vite 성공, 다국어 정적 진입점 663개 생성, Pages `/HOW/` 자산 23개 검증 통과. 이번 데이터와 무관한 기존 chunk 크기 경고는 남음.
- 운영 스냅샷을 재생성하는 npm build의 선행 단계는 실행하지 않고 Vite → localized pages → Pages 검증을 직접 실행해 기존 자료를 보존.
- 기존 HOW 브라우저 회귀: Chrome에서 320/360/390/430/768/1024/1440px × 한국어/영어/일본어 **21건 통과**. 추천 카드 순서·실제 픽스처 비율·가로 넘침 없음, 390px의 전장 카드 클릭과 Reduced Motion 표시 확인. 페이지 JS 오류 없음. `.artifacts/nexon-korea/how-browser/results.json`에 결과 보관. 저장된 OverFast 시험 응답을 이용했으며 한국 통계를 HOW에 표시한 테스트가 아님. 실제 모바일 기기 검증은 아님.
- `git diff --check` 통과. `public/data`, `.github/workflows`, package.json/lockfile의 diff 없음을 확인.

한국/아시아 간 실제 지역 전환, 한국 상세/대시보드/추천 전장/다국어 UI, 자동화 실패 복구/게시 검증은 **운영 연동을 보류했으므로 미검증**이다. 기존 HOW 회귀 테스트 성공을 한국 연동 성공으로 바꾸어 보고하지 않는다.

## 후속 조치

제공처의 수집·재게시 조건 확인 후 STEP 4에 진입한다. 그때 지원되지 않는 조건의 명시적 상태, provider 분리, 집계 시점 호환, 빈 지표 산정 불가, 오류 시 기존 자료 보존을 구현한다. 현재는 소규모 공개 HTML 수집의 기술 가능성과 단일 조건 수치 정합성만 입증했다.
