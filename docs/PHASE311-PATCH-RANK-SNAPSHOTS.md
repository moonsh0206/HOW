## 공식 출처·요약 범위
- 검증 기준: 2026-11-03 미국 리테일 / 2026-11-04 한국 패치. https://overwatch.blizzard.com/ko-kr/news/patch-notes/live/2026/11/#patch-2026-11-03
- 교차 확인: https://overwatch.nexon.com/news/patchnotes/858/patch-2026-11-03
- 일반 영웅 업데이트에 등재된 20명의 영웅만 요약했다. **스타디움 업데이트, 6대6 전용 수치, 그 밖의 영웅 버그 수정은 일반 5대5 밸런스 변경으로 혼합하지 않는다.**
- LLM의 한국어 초안 요약을 공식 숫자·기술명과 대조한 후 버전 관리되는 `src/data/currentPatchNote.js`에 저장했다. 브라우저에서 LLM API를 호출하지 않고, 비밀키를 클라이언트에 배포하지 않는다.
- 한국어 공식 패치에서 일반 영웅 업데이트와 구분이 어려운 내용은 공식 영어 문서와 함께 검토한다. 초기 사전 공지와 최종 라이브 공지가 다른 경우 최종 라이브 내용을 우선한다.
- 메인은 핵심 6명+20명 전체 접기 목록, 상세는 변경된 영웅에게만 간결한 변경 수치와 공식 출처를 표시한다.

## 스냅샷·등급
- 원래 전체/다이아몬드 2개만 공개 스냅샷에 있었으나, `collect-division-batch.js`는 이미 9개 원본 등급을 지원하는 코드였다. 수집을 수동 dry-run 상태에서 매일 실제 수집하도록 workflow를 연결했다.
- 자동 수집: 매일 10:23 KST, PC 일반 경쟁전 전체 전장, 아시아/유럽/아메리카 **각 9개(전체+8개 개별)**, 총 27개 조건. 스타디움은 통계 수집 대상이 아니다.
- 3개 지역 수집에 모두 성공하면 v2 원본 스냅샷을 하나의 인덱스와 함께 Git 커밋하고, 완료 후 Pages 재빌드를 호출한다. API 응답 누락·일부 등급 실패·미완성 로스터는 부분 이력으로 저장하지 않는다. 재시도는 다음 실행에 맡긴다.
- 실제 과거 데이터는 생성하지 않는다. 워크플로가 main 브랜치에 병합되어 **실제 실행에 성공한 시점 이후부터** 신규 관측이 쌓인다. 기존 2개 원본은 보존된다.
- 합성 구간(예: 다이아몬드 이상)은 별도 원본으로 저장하지 않는다. 검증된 동일 패치/집계 구간 또는 **동일 batchId의 동시 수집**에서 필요한 원본 등급이 모두 있을 때만 계산한다. 미확인 패치의 batch는 `patch=null`이며 그래프를 공식 패치 집계로 가장하지 않는다.
- 다른 지역/맵/경쟁전 등급의 기록은 섞지 않는다. 개별 전장, 빠른 대전 등 27개 범위 밖 선택은 기존 라이브 조회만 유지하며 기록이 없는 경우 솔직하게 안내한다.
- 배치 시각은 HOW 관측 시각이며, 제공처 원본 경기 집계 기간·표본 수·정확한 패치 적용 구간은 보장할 수 없다. 패치 직후의 수치 급변은 표본/캐시/메타 변화 가능성을 고려해야 하며 임의 보정하지 않는다.

## 배포와 검증
- 변경은 `feature/nov-2026-patch-all-rank-history` 브랜치의 PR을 통해 검증한다. 메인 병합 전 자동 수집 및 Pages 배포는 활성화되지 않는다.
- 별도 PR CI는 테스트/프로덕션 빌드/Pages 검증을 수행한다.
- 각 패치 영웅의 키·숫자·스타디움 배제, 메인/상세 DOM, 동일 batchId 합성 및 다른 배치 혼용 금지 테스트를 추가했다.
- 라이브 데이터 수집은 이 작업 중 실행하지 않았고, 브라우저 실측도 수행하지 않았다.
