# 넥슨 한국 통계 공개 전달 구조 조사

확인일: 2026-11-24 KST. 사용자에게 넥슨이 공개 Open API 미제공으로 답변했다는 전제를 유지하며, API 유무를 재조사하지 않았다. Chrome의 새 비로그인 context에서 공식 페이지와 실제 UI 필터만 사용했다. 인증·쿠키·토큰·CAPTCHA 우회, 추측한 endpoint 탐색, 내부 API 재호출은 하지 않았다.

## STEP 1 — 부분 완료, HTML 방식 시험 수집 가능

공개 진입점은 [공식 영웅 통계](https://overwatch.nexon.com/hero/rate)다. 문서 응답 HTML에 실제 영웅 행과 `#__NUXT_DATA__`의 공개 통계가 포함된다. Nuxt의 참조 테이블 안에서 `hero-rate-filters`, `hero-rate-list` 두 항목만 추출할 수 있다. HTML 문자열을 실행하거나 전체 앱 state를 역직렬화하지 않는다.

기본 화면은 한국/PC/빠른 대전 역할 고정/전체 전장이다. 최초 페이지 로드에서 통계용 성공 Fetch/XHR 응답은 관찰되지 않았다. 별도 인증·분석 서비스 요청은 통계가 아니므로 수집 대상에서 제외했다. 독립 JSON endpoint의 성공 응답·호출 계약은 **미확인**이다. 공개 정적 클라이언트에는 `fetchHeroRate`/`fetchHeroRateFilters` 사용이 있지만 이것만으로 공식 API 계약이나 재사용 허가라고 해석하지 않는다.

UI에서 경쟁전과 다이아몬드를 선택해 실제 생성된 주소:

```text
https://overwatch.nexon.com/hero/rate?role=all&rq=2&rank=diamond&map=all&input=pc&region=korea
```

클라이언트 내 필터 변경 경로에서는 통계를 불러오지 못했다는 공식 UI 오류가 나타났다. 당시 성공 JSON 응답은 없었으며 실패 요청 URL·브라우저 오류가 충분히 기록되지 않아 CORS/인증/서버 장애 중 어느 것인지 단정하지 않는다. 이후 위 **실제 공개 페이지 주소로 문서 탐색**한 시험에서는 HTTP 200과 정상 SSR 통계·54개 화면 행을 확인했다. 이는 차단 우회나 내부 API 직접 호출이 아니다. 따라서 조사한 안정 후보는 현재 HTML SSR 방식이며 클라이언트 Fetch 방식은 사용하지 않는다.

공개 통계 entry의 구조:

```js
{
  status: "success", message: null,
  data: { list: [{
    heroId, name, role, subrole, colorCode, thumbnailUrl,
    winRate, pickRate, banRate
  }] }
}
```

시험 파일에는 이미지·색상 등 불필요한 항목을 제외하고 heroId/name/role/세 비율만 보관한다. 승률·픽률·밴률은 0~100 백분율이다. 수집 시각은 별도로 기록하며, 검증 가능한 원천 갱신 시각·집계 시작/종료·표본 수는 확인되지 않아 `sourceUpdatedAt:null`로 둔다. 화면의 패치마다 갱신된다는 일반 소개를 개별 관측의 패치 적용 시각으로 바꾸지 않는다.

## STEP 2 — 단일 조건 수집 및 화면 대조 완료

수집: 2026-11-24 12:07:20 KST. 문서 1회, 조건은 위 주소와 동일하다. `scripts/nexon/collect-korea-stats.js`는 기존 trial 파일이 있으면 재수집을 거부한다. `.artifacts/nexon-korea/trial.json`과 `verified.json`은 Git 제외 로컬 자료이며 운영 JSON이 아니다. 네트워크 시험을 전체 단위 테스트에서 재실행하지 않는다.

54명 모두 HOW fixture의 hero key와 직접 일치했다. 누락·중복·신규 미매핑 영웅 0명, 역할 충돌 0명. 돌격 15, 공격 23, 지원 16명이다. hero name으로 key나 역할을 추정하지 않는다. 이름 표시는 CSS 대문자 변환(D.Va/D.Mon)만 허용해 대조했다.

## 이용 조건과 다음 단계

[넥슨 일반 이용약관](https://member.nexon.com/policy/policywrapper.aspx?date=20240322&policytype=31)의 제11조 제1항 제4호는 사전 승낙 없는 서비스/취득 정보 복제·유통·상업적 이용을 제한하고, 제17조는 권리와 영리 목적 이용을 다룬다. 이 조항이 본 공개 통계의 연구·캐시·팬사이트 게시 각각에 어떻게 적용되는지는 제공처 확인이 필요하다. 공개 접근이 가능하고 robots에서 경로를 막지 않는 것만으로 허가를 추정하지 않는다. 일반 Open API 약관을 본 웹페이지의 허가로 대신하지 않는다.

**STEP 4의 수집·저장·공개 표시 이용 조건 충족은 미확인**이다. 따라서 운영 provider 연결·한국 지역 UI 추가·자동 수집/게시를 진행하지 않는다. 이는 API 기술 불가능 판정이 아니라 사용자가 정한 단계 gate에 따른 보류다. 담당 제공처에 자동 수집, 로컬/서버 보관, 파생 계산, 공개 JSON/화면 재게시, 출처 표시, 호출 빈도/보존 기간을 확인해야 한다. 이번에 문의 발송·동의·계정 생성은 하지 않았다.

실제 증거는 `.artifacts/nexon-korea/`에 보관한다. 스크린샷은 원천 페이지이며 HOW에 한국 화면을 구현했다는 증거가 아니다. 시험 스크립트는 기존 QA용 Playwright 캐시와 로컬 Chrome을 사용하며 새 운영 라이브러리를 추가하지 않았다.
