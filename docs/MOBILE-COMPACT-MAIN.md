2026-11-10 로컬 구현. PC 스타일과 통계 계산은 유지했다.

시작점은 약 308px 앞당겨졌다. 첫 카드 끝은 약 838px로 첫 화면에 들어온다. 이미 이전 작업에서 배너가 축소되어 있었으므로 이번에는 높이를 더 줄이지 않고 165px로 안정화했다. 제목도 현재 로컬 20px에서 요청 범위 안인 22px로 조정했다. 배너 설명은 11px 두 줄에서 12px 한 줄로 바꿨다. PC 문구와 원본 배경 파일은 그대로다. CTA는 44px 터치 높이를 유지한다.

## 구조

지역·등급은 상시 표시한다. 모드·전장은 기본 접힘인 ‘상세 필터’ 안으로 기존 DOM을 이동한다. 기본값과 다른 조건은 summary에 표시한다. 기존 select, change 이벤트, 커스텀 팝업과 등급 아이콘을 재사용한다. 데스크톱·메타픽·상세 화면으로 이동하면 원래 위치로 돌려놓는다.

긴 출처/조회 시각과 통계 상태·품질 안내는 ‘OverFast API · 조회 정보’ 안에 모두 보존했다. 오류·오래된 통계는 닫혀 있어도 ‘통계 상태 확인 필요’라고 표시한다. 모바일 패치노트는 실제 날짜·제목과 펼침 버튼만 기본 노출하고 요약·상세·공식 링크는 펼쳐서 확인한다. PC로 복귀하면 기존 위치로 돌린다.

검색과 역할 버튼은 44px 이상, 검색 입력과 콤보박스 선택 문자는 16px다. 정렬을 포함해 기능과 원본 통계는 변경하지 않았다. 영웅 카드 지표도 숨기지 않았다.

## 브라우저 검증

설치된 Chrome의 headless Playwright를 사용했다. 기존 저장된 실제 통계 JSON과 API fixture를 네트워크 응답으로 재생했으며, 새로운 실시간 통계 수집은 하지 않았다. 배경 이미지는 기존 실물 자산을 사용했다. 웹폰트 요청은 차단했다. 실제 iOS Safari 기기는 미검증이다.

1024/1440/1920px의 측정된 헤더·배너·제목·조회 조건·필터·패치노트 좌표와 높이는 수정 전후 동일하다. PC 2열과 사이드바 인사이트 5개를 확인했다. 모바일 3개 메뉴, 화면 너비 왕복 시 단일 DOM/ID 유지와 메뉴 전환 시 추가 통계 요청 없음도 확인했다.

390px에서는 상세 필터 열기/닫기, 맵 팝업 Enter/Escape, 패치 설명·링크 펼침, 유럽 선택에 따른 실제 기존 유럽 JSON 응답 반영, 16px 입력 폰트, 영웅 상세 진입 scrollY=0을 검증했다. QA 스크립트의 첫 시도는 메타픽 화면에서 목록 전용 컨트롤을 찾다가 실패했으며, 목록 복귀 후 검사하도록 고쳐 최종 통과했다.

## 파일과 증거

- `src/views/compactMainView.js`: 기존 필터/출처 노드의 모바일 전용 이동 및 적용 조건 요약.
- `src/views/heroView.js`, `src/controllers/routingController.js`: 렌더링·경로·화면 너비 변경 시 UI 동기화만 추가. 스크롤 제어 로직은 변경하지 않음.
- `src/views/patchNoteView.js`: 기존 요약을 모바일 details 내부로 이동하고 PC에서 복원.
- `src/styles/navigation.css`: 모바일 메인 범위의 크기·간격 조정.
- `index.html`: PC 문구 보존 및 모바일용 짧은 배너 설명 추가.
- `tests/compactMain.test.js`: 값/이벤트/노드/열림 상태/출처 보존 및 PC 복원 테스트 2개.
- `scripts/qa-mobile-compact.cjs`: 8개 화면 및 상호작용 재현 검사.
