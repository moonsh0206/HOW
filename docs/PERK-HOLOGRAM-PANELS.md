# 일체형 특전 비교와 홀로그램 패널

## 특전 구조

실제 특전 비교 컴포넌트가 있는 **영웅 상세의 특전 탭**을 변경했다. 일반/주요 특전 구분을 유지하며 각 단계를 한 장의 비교 패널로 구성했다. 대시보드에는 기존 주목 영웅 및 TOP 카드의 배경 효과를 적용했다.

기존에는 두 특전 각각에 카드 배경이 있었고 공통 막대는 바깥처럼 보이는 별도 영역이었다. 이제 기존 section이 제목·단계명·좌우 정보·VS·비교 막대를 모두 감싼다. 개별 항목의 중복 배경/테두리는 제거했다. 원래 설명 DOM, 더보기 버튼, 선택 건수, 출처 및 라우팅은 보존한다. 단계 선택이라는 새 기능은 추가하지 않고 기존 일반/주요 특전을 각각 표시한다.

상단은 ‘특전 선택률’과 기존 번역된 단계명, 중단은 두 특전의 아이콘·이름·설명·선택 건수, 하단은 공통 비교 막대다. 큰 퍼센트는 개별 정보 칸에서 제거하고 막대 안에만 표시한다. 비교가 불가능한 예외 상태에서는 막대를 만들지 않고 기존 알려진 개별 수치를 작은 보조 정보로 유지한다.

## 막대와 수치

- 높이: 기존 **10px → 모바일 32px / PC 34px**.
- 왼쪽: 블루 `#1b4668`＋오렌지 글씨 `#ffc178`.
- 오른쪽: 오렌지 `#f3a24c`＋네이비 글씨 `#10283c`.
- 실제 원본 선택률로 채움 너비를 정하고 표시만 소수점 한 자리로 반올림한다. 선택 건수로 다른 비율을 만들거나 합계를 100%로 보정하지 않는다.
- 퍼센트 텍스트는 채움과 분리된 bar 내부 overlay다. 일반적인 비율은 각 구간 중앙에 표시한다. 20% 미만 또는 합계 미달은 전체 트랙의 좌우 라벨 위치로 전환하고 작은 중립 배경으로 가독성을 확보한다. 따라서 0.1% 구간의 너비를 숫자 때문에 늘리지 않는다. 라벨은 항상 막대 안에 있다.
- 합계 미달은 남은 중립 구간과 기존 안내를 유지한다. 합계 초과·결측·잘못된 동일 모집단은 기존 Model 검증대로 공통 막대를 생성하지 않는다.
- 막대의 접근성 이름에 두 특전 이름과 비율을 제공하고, 중복 시각 라벨은 aria-hidden으로 처리했다.
- 활성 특전 탭에서 막대는 420ms `cubic-bezier(.22,1,.36,1)`로 양 끝에서 채워진다. 수치는 별도 층에서 140ms 지연 후 220ms fade-in하므로 찌그러지지 않는다. 단순 동일 데이터 재렌더링은 원래 DOM/키 유지 정책으로 반복을 막는다. 숨긴 탭은 해당 CSS 애니메이션 조건에서 제외되고 Reduced Motion은 즉시 최종 상태를 표시한다.

## 홀로그램

참고 방향은 **미래형 배경의 질감·희미한 빛·느린 움직임**에 한정했다. 레퍼런스의 배지·랭크 문양·캐릭터 위치·글꼴·카드 구성은 복제하지 않았다. 기존 HOW 초상화·티어 표시·브랜딩·카드 구성 및 슬라이드 전환을 유지한다.

이전의 정적 교차선을 제거하고 카드 뒤쪽에 장식 전용 레이어를 추가했다.

- 역할 카드: 청록/블루, 주목 영웅: 앰버/오렌지의 저투명도 기하 패턴.
- 정적인 배경 gradient로 미세한 다각형 패널을 만들고, 좁은 광원층의 transform/opacity만 움직인다. 배경 gradient 위치나 blur/box-shadow를 계속 다시 그리는 방식은 사용하지 않는다.
- 스캔 주기: 역할 카드 **15초**, 주목 영웅 **17초**. 프레임 안쪽 밝기 변화는 **13초**, 기존 주목 영웅 아우라 **9.2초**, Meta Score 마그마 **7.2초**를 유지해 모두 같은 시점에 밝아지지 않도록 했다.
- 광원/패턴은 aria-hidden, pointer-events:none이며 격리된 카드 스택에서 텍스트 뒤에 놓인다. 새로운 배지나 장식 아이콘은 추가하지 않았다.
- 새 역할 카드가 주기적으로 생성돼도 스캔이 처음부터 번쩍이지 않도록 페이지 성능 시계에 맞춘 음수 animation-delay를 적용했다.
- 기존 문서 숨김 상태와 라우트 hidden 상태를 따르고, 하나의 IntersectionObserver로 TOP 영역이 화면 밖이면 새 배경 효과를 일시정지한다. view.destroy에서 observer를 해제한다. 추가 setInterval이나 프레임별 JS 루프는 없다.
- Reduced Motion은 정적 패턴과 일정한 밝기만 남기고 스캔을 숨긴다. 기존 초상화 feather 마스크는 그대로 유지한다.

## 실측 비교

한국어·동일 저장 응답·Chrome 100% 기준. 특전 높이는 제목부터 공통 막대까지 포함한 **한 단계 전체 section**을 비교한 값이다.

| 너비 | 단계 패널 전 | 후 | 공통 막대 전→후 |
| --- | ---: | ---: | ---: |
| 320px | 250.59px | 237.39px | 10→32px |
| 390px | 230.09px | 237.39px | 10→32px |
| 1440px | 260.63px | 234.23px | 10→34px |

390px는 외곽 컨테이너와 굵은 막대를 확보하면서 단계당 약 7.3px 증가했다. 모든 너비를 줄였다고 보고하지 않는다. 320px와 PC는 전체 높이가 줄었고 설명을 강제로 잘라 높이를 고정하지 않았다. 설명 펼침 시 패널이 자연스럽게 커진다.

대시보드 역할/주목 카드의 크기는 전후 동일하다. 390px는 TOP 각 156px·주목 126px, 320px는 156/156/136px·주목 126px, 1440px는 네 카드 모두 128px를 유지했다. [원시 비교](qa/perk-hologram/comparison.json).

## 브라우저와 테스트

- **320·375·390·430·768·1280·1440px × KO/EN/JA = 21조합 통과.** 막대가 패널 안에 있는지, 라벨 경계와 퍼센트 위치, 가로 넘침, 카드 크기 보존, 모바일 설명 토글 및 탭 왕복 상태를 검사했다. PC는 원래 전체 설명이 표시된다. [결과](qa/perk-hologram/after/measurements.json).
- **390/1440px 실제 모션 검사 통과.** 홀로그램의 시간별 transform/opacity, 화면 밖 일시정지, Reduced Motion, 공통 막대 시작·중간·종료 및 실제 값/너비/높이 불변을 확인했다. 문서 숨김 처리는 브라우저에서 hidden 속성과 visibilitychange 이벤트를 모의해 확인했으며 실제 OS 백그라운드 전환을 측정했다고 주장하지 않는다. [모션 결과](qa/perk-hologram/motion/results.json).
- **테스트 전용 경계 비율:** 50:50, 80:20, 99.9:0.1, 0:100, 0:0, 12:34를 320/390/1440px에서 검사했다. 채움 너비가 원본 비율 그대로인지와 라벨이 트랙 안에 있는지를 확인했다. 최종 CSS 색상/중립 라벨 배경 합성을 기준으로 계산한 최소 대비는 **약 6.20:1**이다. 이 수치는 운영 관측 데이터가 아니라 명확히 표시한 UI 테스트 fixture다. [결과](qa/perk-hologram/fixtures/results.json).
- 기존 실제 저장 원본의 **54명·216개 특전·108개 단계** 바인딩과 건수/비율 무변경 검사를 유지했다. 위치 검증만 기존 카드 바깥 숫자에서 새 bar 내부 숫자로 강화했다.
- 전체 테스트 **372/372 통과**. 기존 369개를 유지하고 극단 비율/결측 UI 2개와 장식 레이어·observer 해제 1개를 추가했다. [로그](qa/perk-hologram/tests.txt).
- 프로덕션 빌드 성공: 다국어 정적 진입점 663개. 역할 평균 파생 파일 changed:false. Pages `/HOW/` 검증 성공, 로컬 에셋 18개. `git diff --check` 통과.
- 브라우저 통계는 저장된 실제 API 응답을 재생했다. 이번 UI 작업은 API·캐시·Meta Score·특전 산정 및 수집 정책을 변경하지 않았다. 새 외부 이미지·폰트·차트/애니메이션 라이브러리를 추가하지 않았다.

## 수정 파일 및 남은 확인

앱:

- `src/views/heroDetailView.js`, `src/views/perkStatisticsView.js`: 통합 패널과 내부 라벨.
- `src/views/metaDashboardView.js`: 장식 레이어, 안정된 스캔 위상, 화면 밖 관찰자.
- 새 `src/styles/panelEffects.css`, `src/main.js`: 범위가 제한된 패널/효과 스타일.
- `src/styles/mobileRebuild.css`: 이전 정적 교차선 패턴 제거.
- `src/i18n/dashboard.js`: 비교 제목 3개 언어.

테스트/검증:

- `tests/perkPanel.test.js`, `tests/metaDashboard.test.js`, `tests/perkCardBinding.test.js`, `tests/perkStatistics.test.js`.
- `scripts/qa-perk-hologram.cjs`, 본 문서와 `docs/qa/perk-hologram/`.

실제 저사양 모바일 기기의 FPS·배터리 벤치마크는 수행하지 않았다. CSS transform/opacity 중심과 화면 밖 정지로 부하를 제한했으며, Chrome 검증에서 JS 오류나 레이아웃 넘침은 없었다. 기존 500kB JS 번들 경고는 남아 있다. 아주 작은 비율은 숫자를 해당 미세 구간에 억지로 넣지 않고 트랙 내부의 좌우 overlay로 표시한다.

Commit·Push·배포는 수행하지 않았다.
