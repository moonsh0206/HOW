# Phase 6 개인 전적 대시보드

## 기존 문제와 구성

기존 전적 요약은 긴 문장 안에 플레이 시간·경기 수·승패·승률이 섞여 있었고, 영웅 목록도 작은 설명 두 줄에 통계를 모아 표시했다. 상세 지표는 API 응답에 있어도 모델에서 버려져 사용할 수 없었다.

프로필 아이콘·이름·공개 상태·즐겨찾기와 역할별 등급을 헤더에 정리했다. PC는 프로필과 등급을 같은 행에, 모바일은 자연스러운 세로 흐름으로 표시한다. 역할은 돌격→공격→지원 순이고, 실제 제공되는 콘솔 등급도 별도로 유지한다. 없는 등급은 미제공이며 이미지나 디비전을 만들지 않는다.

그 아래에 승률/KDA/경기 수/플레이 시간 4카드를 배치했다. 승률 바로 아래에 같은 응답의 승·패를 표시한다. 영웅별 행에도 승률 바로 아래 해당 영웅의 승·패를 표시한다. PC 행은 이름/시간/승률/승패/KDA를 가로 정렬하고, 모바일은 이름·승률을 먼저, 시간·KDA·경기 수를 짧은 보조 행으로 표시한다.

영웅 행 전체의 native details/summary를 열면 같은 영웅의 상세 통계가 나온다. 키보드 Enter/Space를 지원하며 최소 터치 영역을 유지한다. 닫힌 행의 시간 막대는 기존 최장 플레이 영웅 대비 비율이며 실력·승률 막대가 아니다. 여러 영웅을 빠르게 열어도 추가 비동기 조회가 없고, 같은 플레이어의 언어·즐겨찾기 갱신에는 열린 항목을 유지한다. 다른 playerId로 이동하면 초기화한다.

## 실제 API 범위와 정확성

[공식 OpenAPI](https://overfast-api.tekrop.fr/openapi.json)의 `StatsSummary`, `TotalStatsSummary`, `AverageStatsSummary`를 확인했다.

- `/players/{id}/summary`: 프로필·플랫폼/역할별 등급·API 시즌 정보.
- `/players/{id}/stats/summary?gamemode=competitive&platform=pc`: 전체/영웅별 경기 수, 승, 패, 초 단위 시간, 승률, KDA, 합계 및 **10분당 평균**.
- 상세에서 제공하는 합계·10분당 평균: 처치, 도움, 죽음, 피해, 치유.
- 기존 모델은 `total`/`average`를 버렸다. 이제 검증된 다섯 수치만 보존한다. 영웅 상세도 이 경쟁전 요약을 재사용하므로 **추가 API 요청 0회**다. career 엔드포인트를 새로 호출하지 않았다.
- API의 승률은 표시할 때만 한 자리로 반올림한다. 원본 31.58%는 그대로 두고 31.6%로 표시한다. KDA는 API 값을 두 자리로 표시하며 K/D로 재계산하지 않는다.
- 승패가 모두 제공될 때만 기록을 표시한다. null은 0으로 바꾸지 않고, 실제 0은 유지한다. 경기 수와 승패 합계가 달라도 보정하거나 비율을 다시 계산하지 않는다.
- API가 제공한 과거 시즌·갱신 시각과 HOW 조회 시각을 유지한다. 현재 시즌 또는 실시간 수치라고 단정하지 않는다. 콘솔 등급과 PC 경쟁전 기록은 구분한다.
- 영웅별 무기 명중률·기술별 상세 기록 등 career 전용 지표는 이번 UI에 추가하지 않았다. 실제 요약 필드만 제공한다.

## 실제 공개 계정 조회

`TeKrop#2217`의 summary와 PC competitive summary를 각각 1회 요청해 **둘 다 HTTP 200**을 받았다. 제공된 기록은 19경기, 6승 13패, 승률 31.58%, KDA 1.71, 12,164초, 영웅 5명이다. API 프로필의 갱신 시각은 과거이며 최신 시즌이라고 해석하지 않았다.

`docs/qa/player-dashboard/live/`에 응답과 HTTP 상태·수집 시각·헤더를 기록했다. 운영 스냅샷에는 저장하지 않았다. API 명세 조회는 이 두 플레이어 요청과 별개다.

브라우저는 이 실제 수집 응답을 네트워크 mock으로 재생하여 반복 호출하지 않았다. 검색→카드→프로필에서 플레이어 요청은 검색/summary/competitive 합계 3회였고, 영웅 열기/닫기·즐겨찾기·언어 전환에서 추가 플레이어 요청은 0회였다. 기존 TTL·요청 공유·제한 재시도·429/503 처리는 변경하지 않았다.

PC 헤더는 약 32.6%, 행은 약 17.8% 줄었다. 모바일 행은 약 15.7% 줄었다. 새 4카드 영역 자체의 높이는 PC 99.28px, 모바일 154.75px다. 모바일은 주요 통계의 가시성을 확보하는 대신 첫 영웅 시작이 약 72px(320에서는 약 90px) 내려갔다. 320에서 글자를 과도하게 줄여 첫 화면에 억지로 넣지는 않았다. 내용과 언어에 따라 높이는 달라진다.

320/390/430/1440 × KO/EN/JA **12조합 통과**. 가로 넘침·페이지 오류 없음. 영웅 상세 열기/닫기, 두 통계 그룹, 실제 수치, 즐겨찾기 유지, 언어 전환 후 동일 플레이어·펼침 상태·요청 수 유지 확인.

390/1440 한국어에서는 기존 원격 프로필 아이콘·영웅 초상화 및 로컬 티어 이미지 총 7개가 실제로 로딩된 것을 별도로 확인했다. 새 이미지를 검색하거나 다운로드해 배포 자산으로 추가하지 않았다.

비공개·무등급·기록 없음·승패 일부 누락·합계 불일치·오류/이전 정보·빠른 플레이어 전환은 단위/기존 회귀 테스트로 검증했다. 모든 오류를 실제 API 장애로 발생시킨 것은 아니다. 임의 티어 평균·백분위·가상 순위는 없다.
