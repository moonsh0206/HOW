# 플레이어 검색 카드·영웅별 막대 색상

## 변경

검색 카드에서 긴 playerId 텍스트를 제거했다. ID는 기존 데이터, data-player-id, 링크 및 API 경로에 그대로 유지한다. 같은 닉네임도 각각 다른 ID 링크로 이동한다. 카드 전체가 링크이고 프로필 아이콘·닉네임·공개 상태·PC 경쟁전 시즌·돌격/공격/지원 등급·화살표를 표시한다. 미제공 역할은 ‘정보 없음’이며 임의 등급 이미지를 만들지 않는다.

기존 `renderPlayerRank`와 `public/assets/ranks/*.png`를 재사용했다. 이미지 원본 비율을 유지하고 오류 시 등급명·디비전 텍스트를 남긴다. PC 3열, 768px 이하 2열, 430px 이하 1열 규칙은 유지했다. 카드 등급 갱신은 카드 안의 등급 부분만 교체해 링크 포커스와 클릭 동작을 보존한다.

`src/data/playerHeroColors.js`에 현재 실제 영웅 54명의 고정 HEX 매핑을 추가했다. 기존 초상화의 대표색을 참고한 HOW 표현용 팔레트이며 공식 지정 색상이라고 주장하지 않는다. 예: 바티스트 #67b9cf, 아나 #9cb4d9, 캐서디 #cf7c72. 새 영웅/미매핑 키는 #9aabc0이다. 역할별 막대 CSS를 이 키별 색상으로 대체했으며 시간·막대 길이·정렬·승률·KDA·경기 수 계산은 변경하지 않았다.

## 추가 API 요청량

검색 응답에는 경쟁전 등급이 없어 기존 Provider의 `summary(id)`를 지연 조회한다.

- IntersectionObserver로 viewport 및 80px 주변에 들어온 카드만 조회 대상으로 등록.
- 검색 결과 페이지당 최대 20개 요약 시도, 배경 요약 요청 동시 최대 2개.
- 비공개로 확인된 카드는 요약 자동 조회 생략.
- 각 ID 중복 방지. 기존 Provider의 진행 Promise와 10분/Age 캐시 재사용.
- 검색/화면 변경 시 이전 대기열을 중단하고 늦은 응답을 새 결과에 반영하지 않음. 이미 시작한 요청 최대 2개는 완료될 수 있으나 오래된 화면을 덮어쓰지 않음.
- 429/503 발생 시 나머지 자동 등급 대기열 중단. 실패 카드도 전체 링크는 유지.
- 전체 검색 결과를 무조건 즉시 조회하지 않으며 영웅별 전적은 카드 단계에서 요청하지 않음.

공개 결과 20개를 모두 화면에 노출시키면 최악의 추가 요청은 summary 최대 20회다. 검색 1회와 합쳐 21개의 플레이어 요청이며, 상세 선택 시 summary 캐시가 유효하면 추가 stats 요청 1회만 필요하다. 사용자에 의한 프로필 조회는 이 배경 요청 제한과 별도이며 기존 Provider 오류/캐시 정책을 유지한다. 기존 모스트 배경용 영웅 상세 요청은 변경하지 않았다.

실제 **TeKrop** 1개 결과 검증에서는 검색 1회 + 카드 summary 1회 + 선택 후 경쟁전 stats 1회 = 플레이어 API 총 3회였다. 상세 선택에서 summary 중복 요청은 없었다. 이전 흐름도 총 3회였으므로 끝까지 프로필을 보는 경우 순증은 0회이고, 결과만 보는 경우 카드 등급을 위해 요약 1회가 앞당겨 추가된다. 프로필 새로고침은 기존 정책대로 summary/stats 2회를 다시 요청한다. HTTP 기록은 browser-results.json을 참고한다.

IntersectionObserver가 없는 구형 환경에서는 자동 카드 등급 조회를 생략하고 프로필 링크를 유지한다. 요약 조회 한도 도달·제공처 오류·비공개이면 카드 안내를 표시하며 프로필에서 확인할 수 있다. 미배치와 단순 미제공을 구분할 정보가 없으면 ‘정보 없음’이라고 표시한다. 콘솔 등급은 기존 전용 프로필에 유지하고 검색 카드 범위는 PC다.

## 검증

- 기존 232개 유지 + 새 4개 = **236/236 테스트 통과**.
- 54개 실제 영웅 키의 매핑, 동역할 영웅의 다른 색, 미매핑 폴백 검증.
- ID 비노출/동명이인 링크, 조회 실패 후 이동, 비공개 생략, 최대 동시 2개·20개 상한, 이전 검색 응답 무시, Provider 캐시 공유, 호출 제한 시 대기열 중단 검증.
- Chrome 320/375/390/430/768/1024/1440px에서 카드 등급·PNG 디코딩·ID 비노출·프로필 이동·뒤로 가기·직접 새로고침·기존 막대 비율 및 다른 영웅 색 확인. 가로 넘침 0.
- 1440px는 실제 공개 계정 API로 검색·summary·stats HTTP 200. 나머지는 이전 실제 응답을 재생했다. 실제 동명이인 20명 API를 대량 조회하지 않았으며 부하/오류는 모의 응답으로 검증했다. 실제 모바일 기기는 미검증이다.
- build, verify:pages, git diff --check 통과. 기존 미커밋 작업 보존. Commit/Push/PR/배포 없음.
