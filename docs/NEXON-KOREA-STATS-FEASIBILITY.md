# 넥슨 오버워치 한국 통계 연동 타당성

확인일: 2026-11-24. 이번 단계는 공개 페이지·클라이언트 자산·공개 문서 조사만 수행했다. HOW에 넥슨 통계 어댑터, 수집기, 스케줄 또는 운영 데이터를 추가하지 않았다.

## 결론

**기술적으로 별도 한국 통계 소스로 분리할 가능성은 있지만, 현재 HOW의 OverFast Asia 통계를 대체하거나 섞어 게시할 준비는 되지 않았다.** 공개 화면이 존재하는 사실과 재수집·보관·재배포 허용은 다르다. 문서화된 오버워치용 Open API, 재사용 허용 범위, 집계 기간·캐시·실제 API CORS가 확인돼야 한다.

## 확인한 사실

- [공식 영웅 통계](https://overwatch.nexon.com/hero/rate)는 역할·모드·전장·입력·지역 조건과 영웅별 수치를 제공한다. 확인한 기본 화면은 한국/PC/빠른 대전 역할 고정이었다. 이 기본값을 경쟁전 또는 현재 HOW의 Asia 조건과 동일시하지 않는다.
- 공개 HTML HTTP200, 약208KB, Nuxt 기반 SSR 데이터가 존재했다. 페이지가 실제 참조하는 앱 자산과 hero-rate 화면 모듈 각1개를 읽었다. 클라이언트에서 `fetchHeroRate`, `fetchHeroRateFilters`와 `role/rq/rank/map/input/region` 조건 사용을 확인했다. 한국 조건에서 console 입력을 제외하는 코드도 있다.
- HTML 공개 설정에는 `overwatch-api.nexon.com` 등의 호스트가 나타나지만, 이것만으로 제3자용 API라는 의미는 아니다. 이번에는 해당 호스트의 미확인 경로를 추측하거나 호출하지 않았다. 인증·접근 제어 우회도 하지 않았다.
- 공식 HTML 응답에는 Access-Control-Allow-Origin이 없었다. 따라서 Pages 브라우저에서 그 HTML을 fetch하는 방식을 전제할 수 없다. **실제 통계 endpoint의 CORS는 별도 미검증**이다.
- [robots.txt](https://overwatch.nexon.com/robots.txt)는 조회 당시 `/health`, `/preview`, `/paid-item`을 제한했다. `/hero/rate`가 이 목록에 없다는 사실은 재배포·이미지 사용·자동 수집에 대한 라이선스가 아니다.
- [NEXON Open API](https://openapi.nexon.com/ko/)와 [게임 목록](https://openapi.nexon.com/ko/game/)에서 이번 공개 열람만으로 오버워치의 문서화된 통계 API 계약을 확인하지 못했다. 검색에서 못 찾은 것을 API가 절대 없다는 증거로 사용하지 않는다.

## 이용 조건과 미확인 사항

[NEXON Open API 이용약관](https://openapi.nexon.com/ko/support/terms/)은 허용된 범위의 이용·표시와 데이터/IP 권리 및 저장·가공·배포의 제한을 다룬다. 이 약관이 공개 웹사이트의 내부 통계 인터페이스 사용까지 허용한다는 근거는 확인하지 못했다. 해당 화면은 [넥슨 일반 이용약관](https://member.nexon.com/policy/stipulation.aspx)으로도 연결된다. 일반 약관 본문과 오버워치 개별 정책의 자동 수집 허용 여부는 이번 조사에서 완전히 검증되지 않았다.

실제 연동 전 담당 제공처에 확인해야 할 항목:

1. 팬사이트의 자동 수집·파생 계산·캐시·공개 JSON 재배포 허용 여부와 출처 표기 방식.
2. 공식 endpoint·인증 방식·호출 한도·재시도/Retry-After·허용된 보관 기간.
3. 한국 지역 범위, 플랫폼/모드/등급 정의, 전장 풀·시즌 경계·통계 집계 시작 시점.
4. 승률·픽률·밴률 단위, 결측/0/센티널 값, 실제 표본 수의 제공 여부.
5. 이미지 자산의 사용 조건과 서비스 변경·중단 시 데이터 삭제/보존 기준.

이번에는 문의 발송·계정 등록·약관 동의·API key 발급을 하지 않았다. 공개 데이터를 읽을 수 있다는 이유로 허용을 추정하지 않는다.

## HOW에서의 기술 설계안 — 미구현

- 기존 `statisticsService`와 별도의 provider adapter를 둔다. 출처는 `nexon-korea`, 지역은 별도 Korea 식별자로 보관하고 기존 `asia`를 재라벨링하지 않는다.
- 공식 조건 metadata를 먼저 검증한 뒤 hero key·map key·등급·단위 매핑을 수행한다. 제공되지 않는 밴률·표본 수를 생성하지 않는다.
- 기존 `normalizeStatistics`의 Blizzard 입력 지원은 참고 가능하지만, 동일 스키마라는 증거가 있어야 재사용한다. 형식 유사성만으로 승률 정의까지 같다고 보지 않는다.
- 권한이 확인되면 허용 범위 내 서버/승인된 배치 수집 → 검증 → 출처별 정적 JSON 게시를 검토할 수 있다. GitHub Pages에 비밀 API key를 넣거나 CORS proxy로 접근 제한을 우회하지 않는다.
- provider·cohort·집계 window·schema version을 캐시/스냅샷/순위 정책 식별자에 포함한다. 기존 OverFast 장기 이력·HOT·Meta Score·전일 순위와 혼합 비교하지 않는다.
- 호출 수는 공식 필터 조합·전체 데이터 endpoint 제공 여부 확인 후 산정한다. 지금 확정된 요청 예산이나 자동화 활성화 계획은 없다.

## 이번 추천 전장 기능과의 관계

이번 기능은 **OverFast만 사용**한다. 기존 HOW 지원 표준 전장31개와 현재 OverFast standard 메타데이터의 교집합을 대상으로 한다. 이 메타데이터에 시즌별 경쟁전 로테이션 표시는 없어 화면에 미확인을 명시했다. '현재 시즌 경쟁전 전장 풀 확정 TOP 3'라고 보장할 수 없다. 별도 검증된 전장 풀 목록이 확보되면 그 목록으로 자격 필터를 강화해야 한다.

콜드 캐시 비용은 전장 수 M × 구성 원본 등급 수 D다. 전체31개 기준 단일 등급31회, 기본 diamond_plus(3등급)는93회다. 메타데이터1회는 일일 캐시, 다른 영웅은 같은 cohort 결과 재사용, 실패/이탈 시 후속 호출 중단이다. 통계는 메모리에서만 사용하며 원본/파생 운영 파일이나 자동 수집 workflow는 만들지 않는다.

## 검증 증거와 한계

`docs/qa/hero-maps/research-http.json`, `robots.json`, 공개 HTML/참조 자산 사본은 조사 시점의 증거다. 내부 API의 인증 계약·CORS·이용 허용·통계 집계 window는 미검증이다. 따라서 현재 결론은 **조건부 기술 타당 / 운영 연동 보류**다. 이번 구현의 추천값에는 넥슨 수치를 사용하지 않았다.
