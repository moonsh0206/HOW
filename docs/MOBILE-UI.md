# HOW 모바일 UI 개선 기록

작업일: 2026-11-02 (Asia/Seoul)

## 변경 범위

- index.html: 영웅 결과 영역 안에 접근 가능한 ul 기반 카드 목록 추가.
- src/views/heroView.js: 같은 Model.visibleHeroes() 결과로 표와 카드 출력. 이름·초상화·역할·즐겨찾기 공통 생성 함수 사용. 기존 Controller의 data-hero/data-favorite 이벤트를 그대로 사용.
- src/styles/main.css: 600px 이하 카드 레이아웃, 601px 이상 기존 표 유지. 검색·필터 재배치, 내비게이션 3열 정렬, 배너 이미지 상단 크롭과 하단 텍스트, 모달 높이·스크롤 개선.
- tests/heroView.test.js: jsdom 기반 DOM 회귀 테스트 추가. package.json/package-lock.json에 개발 의존성 추가. 프로덕션 번들에는 포함되지 않음.
- README.md: 새 모바일 레이아웃과 검증 방법 반영.

Model, Controller, Service의 코드·데이터 계약은 변경하지 않았습니다. API 호출·검색·역할 필터·정렬·즐겨찾기 상태는 기존 경로를 사용합니다. 두 DOM 표현은 CSS display:none으로 전환하여 숨긴 쪽은 키보드와 접근성 트리에서 제외합니다. 화면 너비 변경을 위해 데이터를 다시 요청하지 않습니다.

## 모바일 정보 구조

내비게이션 → 영웅 배너 → 목록 제목/개수 → 검색 → 역할 필터 → 결과 요약/정렬 → 영웅 카드 → 출처/조회 시각 → 즐겨찾기 요약/서비스 안내 순서입니다. 즐겨찾기는 상단 메뉴 및 카드의 별로 바로 접근할 수 있습니다.

카드는 80px 정사각 초상화(350px 이하 64px), 이름과 영문 키, 역할, 별 버튼으로 시작합니다. 하단 3열에는 티어·승률·픽률을 표시합니다. 통계가 없으므로 실제 값이나 등급을 만들지 않습니다. 영웅 이름은 줄바꿈하고 긴 영문 키도 카드 폭 안에서 나눕니다. 이미지 로드 실패 시 이름 첫 글자를 유지합니다.

검색 입력은 16px로 모바일 자동 확대 가능성을 줄이고 필터·별·모달 닫기는 44px 이상 터치 영역을 제공합니다. 상세는 네이티브 dialog를 사용하며 내부 스크롤·44px 닫기·긴 문장 줄바꿈·배경 스크롤 잠금을 추가했습니다. Escape/포커스 트랩은 네이티브 동작을 사용하되 실기기 검증은 남아 있습니다.

## 자동 검증 결과

- npm test: 기존 7개 + 새 DOM 회귀 4개, 총 11개 통과.
- 새 테스트 범위: 카드/표 검색·필터 일치, 즐겨찾기 동시 반영·저장, 필터 변경 시 API 재요청 없음, 마지막 즐겨찾기 제거 후 빈 상태·키보드 포커스, 이미지 실패 대체, 모달 XSS 방지·스크롤 잠금 DOM 계약, 오류·로딩 시 두 레이아웃 함께 숨김.
- npm run build: Vite 프로덕션 빌드 성공.
- npm run verify:pages: /HOW/의 JS·CSS·배너 경로 검증 성공.

jsdom은 네이티브 모달/레이아웃 엔진이 아닙니다. 테스트 내 showModal/close는 DOM 계약 확인용 대체 함수로, 실브라우저 모달 동작 검증 결과가 아닙니다.

## 수동 검증 절차

1. npm.cmd run dev로 로컬 앱을 열고 DevTools의 반응형 뷰포트를 위 7개 너비와 600/601px 경계로 설정합니다. 브라우저 확대는 100%로 둡니다.
2. 로딩이 끝난 목록에서 모바일은 카드만, 601px 이상은 표만 보이는지 확인합니다. 가로 페이지 스크롤이 생기지 않아야 합니다.
3. 긴 이름·영문 키, 검색 결과 없음, 역할/정렬 조합, 즐겨찾기 목록의 해제·새로고침 복원을 확인합니다.
4. 이미지 요청을 차단해 대체 글자를, API 요청을 차단해 오류/재시도를 확인합니다.
5. 모달을 열어 짧은 높이·가로 방향·키보드 표시 상태에서 닫기와 내부 스크롤, Escape, 닫은 뒤 포커스 복귀를 확인합니다.
6. iOS Safari와 Android Chrome에서 터치 대상·입력 확대·배경 스크롤 잠금을 확인합니다.

기존 원본/계획서/인계사항은 변경하지 않았습니다. GitHub Push와 공개 배포는 수행하지 않았습니다. 현재 공개 사이트는 이 로컬 변경을 아직 포함하지 않습니다.
