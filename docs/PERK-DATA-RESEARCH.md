# 특전 선택률 데이터 조사

## 최신 추가 구현 · 2026-11-07

사용자 승인으로 실제 OverLooker 공개 API를 Node에서 수집하여 `public/data/perks/overlooker-perks.json`에 54명/216특전을 저장했다. 브라우저는 BASE_URL 아래 동일 출처 JSON만 읽으며 HOW 지역·등급·전장과 독립적으로 수치를 표시한다. 외부 프록시·fixture 운영 복사는 없다. [현재 수집·표시·검증 결과와 수동 갱신 명령](OVERLOOKER-STATIC-PERKS.md)을 참고한다. 아래 직접 API의 CORS 실패 기록은 과거 경로에 대한 사실로 보존한다.

## 최신 상태 · 2026-11-07

사용자가 제공한 운영자 허가와 정식 공개 API를 기준으로 실제 서비스·정규화·54영웅/216특전 매핑·Minor/Major 선택률 UI를 구현했다. 전체/겐지 API는 HTTP 200이나 현재 GET 응답에 CORS 허용 헤더가 없어 GitHub Pages 브라우저 직접 호출은 실패한다. 우회 프록시나 운영용 정적 fallback을 추가하지 않았다. [최신 구현·API·검증 보고서](OVERLOOKER-PERK-INTEGRATION.md)를 참고한다. 아래의 '미허가/공개 API 미확인' 내용은 당시 조사 기록이며 현재 결론과 구분한다.

## Phase 3 재검토 · 2026-11-03

선택률 연동은 계속 **미제공**이다. 공개 페이지·FAQ·개인정보 정책을 다시 확인했고, 웹 도구로 열리지 않은 `/terms`는 일반 HTTPS GET으로 HTTP 200을 확인해 공개 약관을 읽었다. 내부 엔드포인트 추적, 인증·계정 연결, 운영자 연락, 선택률 수동 복사 또는 자동 수집은 하지 않았다.

| 항목 | 확인 결과 |
|---|---|
| 정식 공개 API / JSON 응답 계약 | 검증하지 못함. 공개 통계 화면은 HTML이며 이를 API 계약으로 간주하지 않음 |
| 재사용 허가 | HOW의 공개 집계 재게시를 허용하는 명확한 근거를 확인하지 못함. 약관의 콘텐츠/소스 라이선스 문구를 통계 라이선스로 확대 해석하지 않음 |
| 데이터 성격 | [통계 소개](https://overlooker.app/stats/perks)와 [FAQ](https://overlooker.app/faq)는 기록된 경기와 화면 인식/게임 이벤트의 집계로 설명함. 투표 통계라고 표시하지 않음. 전체 플레이어 모집단의 대표성은 검증하지 못함 |
| Minor/Major | [겐지 공개 화면](https://overlooker.app/stats/perks/genji)에서 두 단계와 선택 건수/비율을 구분함. 선택 건수와 경기 수는 다름. 화면의 비율을 HOW에 가져오지 않음 |
| 영웅/특전 키 | 영웅 slug 유사성만으로 자동 매핑 금지. 이번 실제 OverFast 겐지 응답은 각 단계 2개, 항목 필드는 name/description/icon이며 안정적인 perk ID 없음 |
| 집계 기간·표본 범위 | 화면에 선택 건수는 있으나 기간/지역/등급/플랫폼 범위 및 분모의 완전한 계약은 확인하지 못함 |
| 최신 패치 | 확인 가능한 패치 ID와 유효 기간 없음. 최신 패치 반영을 보장할 수 없음 |
| CORS·호출 제한 | 승인된 API 주소/문서가 없어 검증 불가. HTML 조회 성공을 API CORS 허용으로 간주하지 않음 |

[약관](https://overlooker.app/terms)과 [개인정보 정책](https://overlooker.app/privacy)은 서비스·기록 콘텐츠의 권리를 설명한다. FAQ는 비공개 소스라고 설명하며 약관에는 저장소 라이선스 관련 문구가 남아 있으므로, 이를 외부 데이터 재사용 허가로 추정하지 않았다. 이는 법적 금지를 단정한 결론이 아니라 **허가를 검증하지 못했다는 상태**다.

구현한 `src/models/perkSelectionModel.js`는 출처·허가 상태·기간·패치·분모·매핑 버전을 가진 미제공 상태를 반환한다. 미래 어댑터의 내부 데이터 계약도 주석으로 명시했지만, 이것은 실제 OverLooker 응답 형식이라는 주장이 아니다. `entries=[]`, 단계별 분모 null이며 API 클라이언트나 가상 그래프를 추가하지 않았다. 상세 페이지의 OverFast 특전 효과·아이콘은 그대로 유지한다.

연동 전 필요한 항목은 공개 API 문서, 재게시 허가와 출처 표기 조건, 안정적인 provider perk ID, 검증된 HOW 매핑 버전, 단계별 선택 분모, 집계 기간·패치·필터, CORS 및 요청 제한이다. 번역 이름·배열 순서·아이콘만으로 조인하지 않으며 교체된 특전의 과거 선택률도 자동 승계하지 않는다.

실제 필드 확인 기록: `docs/research/phase3/perk-schema.json`. 아래는 이전 조사 기록이며 당시 화면 수치를 현재 수치로 재사용하지 않는다.

조사일: 2026-11-02. 공개 페이지와 공개 약관만 열람했으며 내부 API 탐색·자동 수집·인증·외부 계정 연결은 하지 않았습니다.

## 확인한 내용

[OverLooker 특전 통계](https://overlooker.app/stats/perks)는 기록된 경기의 특전 선택을 집계한다고 설명합니다. 사용자 투표라고 표시하지 않습니다. [FAQ](https://overlooker.app/faq)는 게임 이벤트와 화면 인식을 결합해 경기 정보를 기록한다고 설명합니다. 이는 제공처의 설명이며 HOW가 개별 기록을 감사하거나 전체 오버워치 모집단의 대표성을 검증한 것은 아닙니다.

[겐지 공개 페이지](https://overlooker.app/stats/perks/genji)에서 1,683건의 perk picks, Minor와 Major별 선택 비율·선택 횟수 및 전체/경쟁전/빠른 대전 분류를 확인했습니다. 이는 경기 수가 아니라 특전 선택 건수입니다. 이번 페이지에서 집계 시작/종료 기간과 완전한 지역·등급·플랫폼 범위는 확인하지 못했습니다. 숫자는 열람 시점의 예이며 HOW UI에는 가져오지 않았습니다.

공개 페이지를 볼 수 있다는 사실만으로 데이터를 재배포할 수 있다고 판단하지 않았습니다. 공개된 재사용 API 문서·라이선스·허용된 수집 방법을 확인하지 못했습니다. [이용약관](https://overlooker.app/terms)은 서비스 이용과 콘텐츠 권리를 설명하지만 HOW의 통계 재게시를 위한 명확한 허락으로 볼 근거는 확인되지 않았습니다. [개인정보 정책](https://overlooker.app/privacy)은 경기 데이터 수집을 설명하며 데이터 재사용 허가와는 별개입니다.

FAQ의 비공개 소스 설명과 약관의 저장소 라이선스 관련 문구가 일치하지 않는 부분도 있어, 소스 공개/라이선스를 재사용 근거로 추정하지 않았습니다. 필요하면 운영자에게 공개 집계 API, 재배포 허용 범위, 표기 조건, 갱신 주기, 표본·기간 정의를 직접 확인해야 합니다. 이번에 운영자에게 메시지를 보내지 않았습니다.

## 키 연결 검토

OverFast 상세 응답은 hero key로 영웅을 조회하지만 특전 항목에는 name/description/icon만 있고 안정적인 perk ID는 없습니다. OverLooker의 영웅 slug가 같아 보여도 영웅 전체와 특전 식별자가 일치한다는 보장은 없습니다. 한국어와 영어 특전명 비교, 번역, 배열 위치, 아이콘 URL만으로 자동 조인하지 않습니다.

정당한 API가 확보되면 제공처 hero/perk ID ↔ OverFast 영웅 key/검증된 특전 식별 매핑을 버전 관리하고, Minor/Major 구분·언어·패치 또는 유효기간·집계 조건을 함께 검증해야 합니다. 이름 변경·특전 교체 시 매핑을 무효화하고 미제공으로 내려야 합니다. 표본은 Minor와 Major의 각 분모 및 관측 기간으로 구분해야 합니다.

## 이번 구현 결정

OverFast가 제공한 특전 이름·효과·아이콘만 표시합니다. 일반/주요 특전은 각각 실제 배열이 있을 때만 출력하며 누락 시 정보 없음을 안내합니다. 선택률 그래프 영역은 미제공 상태입니다. OverLooker 데이터의 내부 엔드포인트를 사용하거나 수치를 복사하지 않았습니다.
