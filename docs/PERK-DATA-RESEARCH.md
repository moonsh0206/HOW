# 특전 선택률 데이터 조사

조사일: 2026-11-02. 공개 페이지와 공개 약관만 열람했으며 내부 API 탐색·자동 수집·인증·외부 계정 연결은 하지 않았습니다.

## 확인한 내용

[OverLooker 특전 통계](https://overlooker.app/stats/perks)는 기록된 경기의 특전 선택을 집계한다고 설명합니다. 사용자 투표라고 표시하지 않습니다. [FAQ](https://overlooker.app/faq)는 게임 이벤트와 화면 인식을 결합해 경기 정보를 기록한다고 설명합니다. 이는 제공처의 설명이며 HOW가 개별 기록을 감사하거나 전체 오버워치 모집단의 대표성을 검증한 것은 아닙니다.

[겐지 공개 페이지](https://overlooker.app/stats/perks/genji)에서 1,683건의 perk picks, Minor와 Major별 선택 비율·선택 횟수 및 전체/경쟁전/빠른 대전 분류를 확인했습니다. 이는 경기 수가 아니라 특전 선택 건수입니다. 이번 페이지에서 집계 시작/종료 기간과 완전한 지역·등급·플랫폼 범위는 확인하지 못했습니다. 숫자는 열람 시점의 예이며 HOW UI에는 가져오지 않았습니다.

공개 페이지를 볼 수 있다는 사실만으로 데이터를 재배포할 수 있다고 판단하지 않았습니다. 공개된 재사용 API 문서·라이선스·허용된 수집 방법을 확인하지 못했습니다. [이용약관](https://overlooker.app/terms)은 서비스 이용과 콘텐츠 권리를 설명하지만 HOW의 통계 재게시를 위한 명확한 허락으로 볼 근거는 확인되지 않았습니다. [개인정보 정책](https://overlooker.app/privacy)은 경기 데이터 수집을 설명하며 데이터 재사용 허가와는 별개입니다.

FAQ의 비공개 소스 설명과 약관의 저장소 라이선스 관련 문구가 일치하지 않는 부분도 있어, 소스 공개/라이선스를 재사용 근거로 추정하지 않았습니다. 필요하면 운영자에게 공개 집계 API, 재배포 허용 범위, 표기 조건, 갱신 주기, 표본·기간 정의를 직접 확인해야 합니다. 이번에 운영자에게 메시지를 보내지 않았습니다.

## 키 연결 검토

OverFast 상세 응답은 hero key로 영웅을 조회하지만 특전 항목에는 name/description/icon만 있고 안정적인 perk ID는 없습니다. OverLooker의 영웅 slug가 같아 보여도 영웅 전체와 특전 식별자가 일치한다는 보장은 없습니다. 한국어와 영어 특전명 비교, 번역, 배열 위치, 아이콘 URL만으로 자동 조인하지 않습니다.

정당한 API가 확보되면 제공처 hero/perk ID ↔ OverFast 영웅 key/검증된 특전 식별 매핑을 버전 관리하고, Minor/Major 구분·언어·패치 또는 유효기간·집계 조건을 함께 검증해야 합니다. 이름 변경·특전 교체 시 매핑을 무효화하고 미제공으로 내려야 합니다. 표본은 Minor와 Major의 각 분모 및 관측 기간으로 구분해야 합니다.

## 이번 구현 결정

OverFast가 제공한 특전 이름·효과·아이콘만 표시합니다. 일반/주요 특전은 각각 실제 배열이 있을 때만 출력하며 누락 시 정보 없음을 안내합니다. 선택률 그래프 영역은 미제공 상태입니다. OverLooker 데이터의 내부 엔드포인트를 사용하거나 수치를 복사하지 않았습니다.
