# 아시아 경쟁전 등급별 메타 개선

작업일: 2026-11-02 (Asia/Seoul). 기존 Vite·ES Modules·MVC·Provider·Domain과 GitHub Pages 설정을 유지했습니다. 원본/기획서/인계사항을 변경하지 않았고 원격 Push 및 공개 배포를 하지 않았습니다.

## 기존 코드 진단

기존 기본값은 PC/아시아/경쟁전/전체 등급/전체 전장이었습니다. 지역 기본값 오류는 없었지만 전체 등급을 한국 상위권 경쟁전 메타로 해석하면 모집단이 달라집니다. 통계 쿼리는 개별 등급을 선택할 때 competitive_division에 그대로 전달하고, 전체 등급에서는 생략하고 있었습니다. 통계 Service의 캐시·진행 요청·실패 대기는 직렬화한 조건별로 이미 분리돼 있었습니다. 여러 등급 평균을 내는 로직은 발견되지 않았습니다.

기존 메타는 역할 내 승률·픽률 백분위 70:30을 사용하며 승률 단독 함수는 비교용으로 남아 있습니다. 승률 비중이 크면 낮은 픽률의 고승률 영웅도 여전히 높은 티어일 수 있습니다. 단일 점수로 실제 메타를 완벽히 설명하지 못하며, 표본 수/통계 기간/지도별 맥락/밴에 따른 선택 기회/숙련자 편중을 알 수 없습니다.

## 실제 등급 지원 검증

[공식 스키마](https://overfast-api.tekrop.fr/openapi.json)의 CompetitiveDivisionFilter는 bronze/silver/gold/platinum/emerald/diamond/master/grandmaster 8개입니다. 2026-11-02 UTC 06:00부터 각 개별 아시아 등급과 전체 등급, 아메리카 다이아몬드를 순차 조회했습니다. 총 10개 조건 모두 HTTP 200과 54개 레코드를 반환했고 CORS 허용 헤더를 확인했습니다. 각 조건에서 영웅별 수치가 달라 실제 필터 적용을 확인할 수 있었습니다. 요청은 순차적으로 수행했으며 429/503 발생 시 중단하도록 검사 도구를 작성했습니다.

grandmaster 설명은 champion 포함입니다. 화면은 ‘그랜드마스터·챔피언’으로 표시하고 champion 단독 요청은 실제 HTTP 422로 확인했습니다. 제공처가 묶어 주는 버킷을 그대로 사용하며 두 등급을 HOW가 직접 합산하는 것은 아닙니다. 응답에 세부 GM/Champion 표본 수가 없어 내부 포함 비중을 독립 검증한 것은 아닙니다. 한국 전용 등급/지역은 지원하지 않습니다.

원본 검증 응답과 스키마는 tests/fixtures/ranked-cohorts.json, 재현 도구는 scripts/audit-ranked-meta.js에 있습니다. 자동 테스트는 저장된 실제 응답과 Mock을 사용하고 실제 네트워크 테스트는 별도로 실행합니다.

## 기본값과 등급 선택

기본값을 PC/아시아/경쟁전/다이아몬드/전체 전장으로 변경했습니다. 상단 조회 기준 배너 안에 조건 선택을 배치하여 모바일에서도 긴 추천 카드 아래까지 스크롤하지 않고 등급을 바꿀 수 있습니다.

| UI 그룹 | 개별 요청 값 |
| --- | --- |
| 전체 등급 | division all → competitive_division 생략 |
| 일반 경쟁전 | bronze, silver, gold, platinum |
| 중상위권 | emerald, diamond |
| 최상위권 | master, grandmaster(챔피언 포함) |

그룹은 native optgroup 내비게이션이며 API에는 한 개의 실제 등급만 보냅니다. 그룹별 평균이나 임의의 상위 등급 합산을 하지 않습니다. 등급 선택은 44px 이상, 모바일 16px 글자, 설명 연결(aria-describedby)을 유지합니다. 빠른 대전은 전체 등급으로 초기화하고 등급 선택을 비활성화합니다.

## 도미나가 높았던 이유

이번 실제 전체 등급 응답에서 도미나는 승률 53.9%, 픽률 6.7%로, 역할 내 승률 백분위 100·픽률 백분위 53.57이었습니다. 점수 86.07(100×.7 + 53.57×.3), 2위/S이므로 높은 승률의 영향이 컸습니다. 실제 API 데이터를 잘못 만든 것이 아니라 전체 등급 집단과 승률 비중이 함께 만든 결과입니다.

아시아 다이아몬드에서는 도미나와 윈스턴의 승률이 모두 54.6%였지만 픽률은 각각 4.8%와 15.3%였습니다. 같은 역할 내 승률 백분위 96.43을 공유하되 픽률 백분위가 21.43 대 100으로 갈리므로 도미나는 73.93점·5위/A, 윈스턴은 97.50점·1위/S입니다. 같은 조건에서 둠피스트는 77.86점·2위/S, D.Mon은 74.29점·4위/A였습니다. 수집 시점의 값이며 현재 응답이 달라지면 결과도 달라집니다.

영웅 이름별 상수나 수동 보정은 넣지 않았습니다. 70:30을 초기 비교 모델로 유지하고 60:40, 50:50, 40:60, 100:0을 같은 아시아 다이아몬드 집단에서 비교했습니다. 60:40은 역할 순위 24/54명·티어 10/54명, 50:50은 순위 34/54명·티어 24/54명이 기본과 달랐습니다. 이는 가중치 민감도이지 어느 비율이 실제 메타의 정답인지 검증한 결과는 아닙니다. 전체 표와 각 등급 결과는 [실측 비교 보고서](RANKED-META-DATA.md)에 있습니다.

## 점수와 분류의 분리

Meta Tier는 기존처럼 역할 내 완전한 승률/픽률 집단의 백분위 70:30으로 계산합니다. 동률 평균 백분위, 점수 동률 최고 순위 공유, ceil 15/30/50/75% 누적 S~D, 결측 미분류 정책은 유지합니다. 0은 유효하며 누락을 0으로 만들지 않습니다. 픽률 1% 미만 경고도 유지합니다. 이번 그랜드마스터 응답에는 픽률 1% 미만인 영웅이 1명 있었으며 표본 수 추정/신뢰구간/임의 감점은 하지 않았습니다.

추가한 High Win Rate/Popular Picks/Contested Picks는 각각 역할별 승률/픽률/밴률 1위 대표를 따로 보여 줍니다. 동률은 영웅 키순으로 대표 한 명만 표시한다고 UI에서 안내합니다. Hidden Picks는 기존의 높은 승률·상대적 중하위 픽률·최소 1% 규칙입니다. 이 분류는 중복될 수 있고 티어를 덮어쓰지 않습니다.

밴률은 메타 영향력의 별도 관측입니다. 강함 외에도 상대하기 불편함·상성·인식 등이 영향을 줄 수 있고, 밴은 픽 기회 자체에도 영향을 줄 수 있습니다. 따라서 현재 점수에 더하거나 임의로 밴률을 승률로 변환하지 않습니다. HOT은 여전히 동일 조건의 실제 이전 데이터가 있을 때만 표시합니다.

## 혼용 방지와 향후 비교 화면

Controller는 요청한 조건과 Service 결과의 filters가 일치하는지 확인합니다. 조건 메타데이터가 없거나 다르면 오류로 처리합니다. Model도 선택 조건과 다른 통계를 점수에 사용하지 않습니다. 등급 변경 즉시 이전 값과 HOT 이력을 비우고 세대 번호로 느린 이전 응답을 무시합니다. Service 캐시는 region/division을 포함한 전체 쿼리별로 분리돼 다른 조건의 오래된 값을 폴백하지 않습니다.

기존 ALL_RANK_FILTERS를 별도로 두어 로컬 스냅샷 수집은 여전히 전체 등급만 수행합니다. UI 기본값 변경으로 기존 전체 등급 JSON을 다이아몬드 데이터라고 재해석하지 않습니다. 따라서 기본 다이아몬드 조건에 맞는 과거 관측이 없으면 HOT도 미제공입니다. 스케줄이나 수집 범위는 확대하지 않았습니다.

domain/cohortComparison.js의 compareHeroCohorts는 조건·조회 시각·독립 점수 결과를 행별로 반환합니다. 예를 들어 겐지 gold/emerald/diamond/master 행은 각각 해당 등급 전체 역할 집단에서 계산합니다. 동일 조건 중복 행은 오류이며 통계 혼합은 하지 않습니다. 미래 UI는 영웅 행×등급 열로 이 결과를 표시하면 되고, 각 열에 조건·시각·오류/미제공 상태를 둡니다. 현재 앱에 다중 조건 자동 조회 화면은 추가하지 않았습니다. 독립 비교 예시는 실측 보고서에 제공했습니다.

## 검증 및 한계

실제 10개 통계 조건 조회와 champion 단독 422를 확인했습니다. 오프라인 전체 테스트 45개(기존 회귀+실제 응답 스냅샷+Mock/DOM), 실제 API 통합 테스트 3개, 프로덕션 빌드 및 /HOW/ 리소스 경로 검증을 수행했습니다. 실제 API 기본 호출은 PC/아시아/경쟁전/다이아몬드로 확인했습니다.

브라우저 도구가 No browser is available을 반환해 실제 모바일/PC 레이아웃과 스크린샷 검증은 미완료입니다. 등급 optgroup·기본 선택·전환·현재 조건 표시·오래된 응답 무시는 DOM 통합 테스트로 확인했지만, 터치 선택기·글자 잘림·오버플로는 실제 320/375/390/430/768/1024/1440px 브라우저에서 재확인해야 합니다.

한국 전용 모집단·표본 수·정확한 통계 기간·실제 메타 정답은 제공되지 않습니다. 설명 가능한 탐색용 상대 점수로 제공하며 전문 선수 픽·스크림·패치별 인과관계를 완벽하게 측정한다고 주장하지 않습니다.
