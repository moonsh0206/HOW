# 영웅 상세·전장 비교 UI 검증

## 구현

- 전체 전장은 기존 관측 이력, 특정 전장은 같은 그래프 슬롯의 전체/선택 전장 비교로 표시한다. 기존 지표 버튼을 재사용하며 관측 이력 보기로 전환할 수 있다.
- 별도 전장 통계 컨테이너를 제거했다. 원래 상세 통계 안내의 전체 설명은 기존 정보 펼치기에 보존했다.
- 공통 표시 함수로 퍼센트 두 자리, 차이 두 자리 `%p`를 표시한다. 차이는 원본끼리 뺀다. 예: 52.456789 − 52.123456 → +0.33%p. null/undefined/NaN/범위 밖 값은 미제공이다. 실제 0은 0.00%다.
- 순수 `mapComparisonModel`에서 전장 외 필터, 출처 구성, 패치·집계창 호환성을 검사한다. 불일치는 그래프를 보류한다. 관측 시각 차이·캐시 자료는 안내하며 결측/검토 중 값으로 막대를 만들지 않는다.
- 세로 막대는 0에서 시작하고 두 값에 동일 축을 쓴다. 승률은 0–100%, 픽률/밴률은 최대값에 여유를 둔 축(최소 상한 1%)이다. 작은 값을 크게 보이게 하는 최소 막대 높이는 없다. 플롯 높이는 100px다.
- 모바일은 배너·요약·패널 여백을 줄이고, 현재 관측값을 제목 옆으로 정리했다. PC 1280px 이상에서는 카운터와 시너지를 나란히 배치한다. 원래 설명·데이터는 보존하며 핵심 본문 크기를 무조건 줄이지 않았다.

|320|168.80→160.80|1305.20→1186.09|1799.02→1643.31|
|390|168.80→160.80|1264.41→1148.59|1753.13→1620.22|

- Meta Score, 원본 스냅샷, 수집·캐시 정책, URL은 변경하지 않았다. Commit/Push/배포 없음.
