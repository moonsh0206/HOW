## 검증 한계

Computer Use가 Windows 현재 브라우저 URL을 확실하게 확인할 수 없다는 이유로 중단되었습니다. 브라우저 입력을 더 시도하지 않았습니다.

- 실제 브라우저 화면, 콘솔 오류 및 실 API 응답을 포함한 종단간 동작은 미검증입니다.
- 1440px, 768px, 390px 시각 검증은 미완료입니다. 해당 크기 대응 CSS는 구현했지만 스크린샷 확인을 완료했다고 볼 수 없습니다.
- API 공개 문서의 한국어 heroes 계약을 확인했습니다. 실제 사용자 환경의 CORS·네트워크·이미지 접근 가능 여부는 브라우저에서 추가 확인해야 합니다.
- 테스트는 주입한 fixture를 사용하며, fixture가 제품 화면 데이터로 사용되지는 않습니다.

## 브라우저에서 이어서 확인할 항목

1. npm.cmd run dev 후 표시된 URL 열기. 영웅 목록과 초상화, 조회 시각 확인.
2. 1440/768/390px에서 배너 크롭·내비게이션·표·사이드바 확인. 모바일 표 내부의 가로 스크롤 확인.
3. 한국어 이름/영문 키 검색, 역할과 정렬 조합, 결과 없음 안내 확인.
4. 별 버튼으로 저장 후 즐겨찾기 메뉴 이동, 새로고침 후 복원, 해제 확인.
5. 영웅 기본 정보 모달과 Escape 닫기, Tab 포커스 이동 확인.
6. DevTools에서 API 요청 차단 후 새로고침하여 오류 표시, 차단 해제 후 재시도 확인.
7. 저장소 차단 시 안내와 임시 즐겨찾기 확인.
