# Phase 4 플레이어 전용 프로필 UI

## 구현과 라우팅

검색 결과는 실제 링크 `#/players/{encodeURIComponent(playerId)}`를 사용한다. 기존 API 식별자를 보존하고 해시에서 한 번 디코딩한 뒤 Provider 경로 규칙으로 검증한다. `%7C`가 포함된 Blizzard 식별자도 이중 인코딩 없이 API에 전달한다. 검색 결과를 재검색해 ID를 찾지 않는다.

전용 경로에서는 검색 폼/목록을 숨기고 프로필과 ‘전적 검색으로 돌아가기’를 표시한다. 직접 URL과 새로고침에서도 summary·경쟁전 통계를 ID로 조회한다. 검색으로 돌아갔다 다시 선택하거나 뒤로/앞으로 이동할 때는 기존 Provider 캐시를 재사용한다. 새로고침 후 검색 목록 자체는 복원하지 않는다. 영웅 상세 라우트와 기존 스크롤 정책은 변경하지 않았다.

## 모스트 영웅과 데이터

`topPlayerHeroes()`는 **PC 경쟁전** 응답에 존재하는 모든 영웅을 플레이시간 내림차순으로 정렬한다. 동률은 영웅 키로 안정적으로 정렬한다. 양수 플레이시간 최댓값의 영웅만 모스트로 정한다. `formatPlayerTime()`은 실제 초를 시간·분·초로 표시한다.

각 막대는 `hero.seconds / maximumSeconds × 100`이다. 누락 시간은 막대를 만들지 않으며 전체가 0이거나 없으면 모스트/막대를 만들지 않는다. 0초가 실제 제공되고 다른 영웅에 양수 기록이 있으면 실제 0% 막대다. 승률·KDA·경기 수·승패는 기존 응답값 그대로 보존한다. 전체 모드 통계와 혼합하지 않는다.

배경은 기존 `heroDetailService.getHero(most.key)`의 공식 영웅 배경 중 xl+를 우선 선택한다. 새 이미지 검색이나 임의 자산은 사용하지 않았다. 실패·누락·비공개·시간 없음은 기존 HOW `public/assets/hero-banner.jpg`를 기본 배경으로 사용한다. 배경의 늦은 응답은 프로필 세대 번호로 보호하며, 검색으로 돌아갔다가 재진입해도 공유된 영웅 상세 캐시/진행 요청을 재사용한다.

## 등급 이미지

`src/views/playerRankView.js`에서 기존 `src/data/rankAssets.js`의 사용자 제공 PNG 8개를 재사용한다. `ultimate`/`champion`은 실제 존재하는 `public/assets/ranks/champion.png`로 연결했다. 이 매핑은 플레이어 프로필에만 적용하며 영웅 티어 필터에 챔피언 선택값을 추가하지 않는다.

브론즈·실버·골드·플래티넘·에메랄드·다이아몬드·마스터·그랜드마스터·챔피언 이미지 옆에 세부 디비전과 API 시즌을 표시한다. 미제공 역할은 ‘등급 정보 없음’, 미대응 등급은 원본 텍스트를 표시한다. 이미지 오류 시 이미지만 제거하고 등급명·디비전 텍스트는 유지한다. BASE_URL을 재사용해 `/HOW/`에서 로딩된다. 이번 작업에서 티어 자산 원본이나 기존 드롭다운 매핑은 변경하지 않았다.

## UI

배경 위에 네이비 그라데이션을 적용하고 닉네임·등급을 전경에 배치한다. 모바일은 이미지 위치를 65%/30%로 조절하며 역할별 등급을 3열로 유지한다. TOP HEROES는 한 행에 초상화·한국어 이름·시간·기존 지표·막대를 표시한다. 역할 색은 돌격 파랑, 공격 주황, 지원 민트이며 모르는 역할은 중립색이다. 고정 높이로 내용을 잘라내지 않는다.

이번 메시지에 실제 참고 스크린샷 파일이 추가되지 않아 이를 픽셀 단위로 대조했다고 주장하지 않는다. 요청한 TOP HEROES 구성과 HOW의 기존 색상을 기준으로 구현했다.

## 검증

실제 공개 계정 **TeKrop**으로 1440px Chrome에서 닉네임 검색 → 결과 링크 → 전용 URL → 프로필을 검증했다. 검색·summary·PC 경쟁전 모두 HTTP 200이고 직접 프로필 새로고침에서는 검색 없이 summary·통계만 조회했다. 배경에는 실제 공식 바티스트 배경이 로딩됐다.

관측값: 바티스트 6,056초(1시간 40분 56초)가 모스트이며 막대 100%. 아나 5,363초는 88.55680317%, 캐서디 501초는 8.27278732%, 루시우 198초는 3.26948481%, 키리코 46초는 0.75957728%다. API 제공 시즌 22 지원 실버 4 이미지를 확인했다. 현재 시즌으로 재해석하지 않는다.

Chrome 320/375/390/430/768/1024/1440px에서 가로 넘침 0, 검색 복귀·뒤로 가기·재선택 캐시·프로필 새로고침·모스트 배경 디코딩·실버 PNG 로딩·정렬·막대 비율을 확인했다. 1440px는 실제 API, 나머지는 이전 실제 수집 응답과 기존 영웅 상세 응답을 재생했다. 실제 모바일 기기는 미검증이다.

단위 테스트는 복수 ID 링크의 독립 이동, 직접 경로에서 재검색 없음, 경로 검증, 시간/정렬/0/null/비율, 전체 티어 이미지 매핑·이미지 실패 폴백, 지연된 다른 계정 배경의 혼입 방지를 추가했다. 복수의 다른 실계정·챔피언 실계정·실제 비공개 계정을 대량 조회하지 않았으며 해당 경우는 모의 응답/매핑 테스트다. 기존 공개 계정 검증은 유지한다.

최종 테스트 232개 통과, build와 verify:pages 통과. diff 검사와 Git status 확인. 기존 미커밋 Phase 4 검색 작업을 보존했고 운영 Meta Score·영웅 통계·스냅샷·카운터·특전은 수정하지 않았다.

- `src/styles/player.css`: 프로필 헤더·역할별 막대·반응형.
- `tests/playerProfile.test.js`: 새 회귀 테스트 5개.
