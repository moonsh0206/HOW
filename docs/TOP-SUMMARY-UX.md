# 메인 상단 UX 정리

2026-11-02. UI 재배치·설명 축소만 수행했다. API, Meta Score v2, S 자격, HOT/Hidden Picks 계산과 저장 방식은 변경하지 않았다.

## 변경

- 메인 선정 기준 카드와 상세 공식 펼침 영역, 조회 조건 안내 박스를 제거했다. 실제 지역/등급/모드 선택과 조건·출처·조회 시각은 유지했다.
- 티어 안내는 “HOW 메타 티어는 실제 통계를 바탕으로 종합 평가한 결과입니다.” 한 문장만 사용한다. 배지의 기본 툴팁과 클릭 시 작은 팝오버를 제공하며 가중치·S 조건·백분위·점수 기여도는 UI에 노출하지 않는다.
- 상세 페이지의 공식/자격 조건 설명도 제거하고 인사이트의 긴 선정 규칙을 한 문장으로 축소했다. 통계 미제공·추세 부재 안내는 유지한다.
- 즐겨찾기를 제목 아래 조건 요약·출처·조회 시각 다음으로 이동했다. 초상화/이름/현재 조회 조건의 티어를 표시하는 한 줄 칩이며, 기존 상세 이동과 저장 기능을 유지한다.
- 즐겨찾기는 검색·역할 필터와 관계없이 저장된 전체 영웅을 표시한다. 통계가 없으면 미분류이며 가상 티어를 만들지 않는다.
- 빈 상태는 “즐겨찾기한 영웅이 여기에 표시됩니다.” 한 줄이다. PC/모바일 모두 칩 줄 내부만 가로 스크롤하며 페이지 폭을 늘리지 않도록 구성했다.
- 칩 최소 높이 44px, 초상화 30px, 도움말 최대 폭 360px(작은 화면에서는 화면 폭−24px)로 제한했다.

## 변경 파일

- `index.html`: 큰 안내 영역 제거와 즐겨찾기 이동.
- `src/styles/layout.css`: 작은 칩, 빈 상태와 티어 팝오버 스타일.
- `src/views/heroView.js`: 상단 즐겨찾기와 실제 티어 렌더링, 긴 안내 출력 제거.
- `src/views/heroDetailView.js`: 상세 공식 설명 제거.
- `src/views/insightView.js`: 설명 문구만 축소.
- `src/views/tierReasonView.js`: 긴 산정 근거 모달을 짧은 안내로 교체. 계산 코드와 정책 문서는 유지.
- `tests/heroView.test.js`, `tests/metaV2.test.js`, `tests/application.test.js`: 새 UI 기대값, 빈/존재 상태, 실제 티어, 상세 이동과 내부 공식 비노출 검증.
- 본 문서.

## 검증

- `npm.cmd test`: 54/54 통과.
- `npm.cmd run build`: 프로덕션 빌드 통과.
- `npm.cmd run verify:pages`: /HOW/ 기준 로컬 자산 5개 경로 통과.
- DOM 통합 테스트에서 메인 안내 박스 제거, 상단 즐겨찾기 위치, 빈 상태/존재 상태, 실제 영웅 티어, 클릭 상세 이동을 확인했다.
- 브라우저 도구가 **No browser is available**을 반환했다. 실제 PC/모바일의 픽셀 배치·가로 스크롤·터치·네이티브 팝오버 동작과 스크린샷은 검증하지 못했다. CSS 및 DOM 확인을 실제 화면 검증으로 간주하지 않는다.
- GitHub Push·공개 배포는 수행하지 않았다.
