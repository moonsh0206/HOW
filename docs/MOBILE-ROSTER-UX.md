# 모바일 메타 인사이트·패치노트·영웅 목록 개선

2026-11-06. 최신 로컬 구현을 기준으로 실제 코드와 브라우저 화면을 수정·검증했다. 원격 저장소를 읽거나 변경하지 않았다.

## 변경 결과

- 600px 이하: 통계 조건/필터 → 인사이트 5개 → 최근 패치노트 → 검색·역할·정렬 → 영웅 목록 순서다. 기존 비표시 favorites 앵커는 보존했다.
- HOT/숨은 꿀영웅 2열을 유지하고 접힌 ‘상세’ 컨트롤을 대표 정보 옆에 배치했다. 상위 승률/픽률/밴률은 375~600px에서 3열, 320~360px에서는 제목·대표 영웅·상세 버튼을 한 행에 둔 세 개의 컴팩트 행이다.
- 기본 화면에는 대표 1명과 핵심 지표만 표시하고 나머지 영웅·승률 변화·픽률·이유·집계창 경고는 상세에 보존했다. 영어 eyebrow와 중복 코호트 표기는 모바일에서 숨겼다. 빈 상태는 ‘이전 기록 부족’, ‘기록 확인 중’, ‘통계 확인 중’, ‘통계 연결 오류’ 등으로 구별한다.
- 숫자/대표 이름/펼침 설명은 12px 중심으로 유지했다. 카드의 고정 높이·말줄임·콘텐츠 잘라내기를 도입하지 않았다. 대표 링크와 상세 버튼은 서로 다른 영역이며 최소 44px 터치 높이다.
- current-patch-note 노드 하나를 이동한다. 모바일에서는 공식 링크·집계창 안내를 기존 details 안으로 옮기고, 601px 이상에서는 원래 사이드바와 링크 위치로 복귀한다. 날짜·요약 원문·주요 변경·공식 URL 데이터는 변경하지 않았다.
- patch/insight의 모바일 펼침 상태, 리렌더링 및 이동 시 포커스를 보존한다. matchMedia 리스너 하나를 재사용하고 destroy에서 해제한다.
- 모바일 영웅 카드 패딩 10px, 간격 7px, 초상화 48~50px로 정돈했다. 영웅명·역할·Meta 표기와 티어/승률/픽률/밴률·검토 상태를 삭제하지 않았다. 즐겨찾기는 44×44px다.
- 모바일 배너는 내부 여백과 글줄 간격을 줄이고 기존 이미지·소개·CTA를 유지했다. 티어 PNG·plus·전장 그룹·커스텀 드롭다운은 재사용했다.

## 실제 측정 — 390px

같은 로컬 저장 통계, 같은 Chrome viewport로 비교했다. 기본 diamond_plus/전체 역할/기본 HOW 티어순이며 HOT은 이전 누적 기록 부족 상태다.

|---|---:|---:|
| 배너 높이 | 360.8px | 221.2px |
| 인사이트 영역 | 364.8px | 254.0px |
| HOT/꿀영웅 카드 | 143px | 83px |

패치노트가 목록 아래 약 11034px 위치에서 목록 위 약 1036px 위치로 이동했음에도 첫 영웅까지 약 124px 감소했다. 카드 높이는 약 12.5%, 인사이트 영역은 약 30.4% 감소했다. 콘텐츠·빈 상태·폰트 로딩에 따라 높이는 달라질 수 있다.

1440px에서는 배너 400.7px, 패치노트 253.0px, 인사이트 1479.7px 등 기존 위치·치수가 전후 동일했다. 601~1100px는 기존 태블릿 1열 레이아웃과 사이드바 위치를 유지한다.

## 실제 브라우저 검증

Playwright + 설치된 Chrome의 별도 headless 프로필을 사용했다. Computer Use URL 검증을 우회하거나 사용자 Chrome 프로필에 연결하지 않았다. 앱 의존성/lock 파일을 변경하지 않고 도구를 node_modules/.cache/how-mobile-qa에 격리했다.

- **320/360/375/390/430/600/601/768/1024/1440px** 각각 실제 렌더링·스크린샷을 확인했다. 모든 폭에서 문서 가로 넘침 0px, 인사이트 5개, 올바른 패치노트 부모를 검사했다.
- 320px/390px의 인사이트 전체 펼침에서도 가로 넘침이 없었다. summary 터치 영역과 즐겨찾기 44px를 브라우저에서 검사했다.
- 패치노트 Enter 조작, 390→768→390 전환 후 열린 상태/포커스/단일 노드 보존을 확인했다.
- 티어/전장 팝업을 열어 실제 elementFromPoint 결과로 다른 카드에 가려지지 않는지 검사하고 스크린샷을 남겼다. Escape로 닫기를 확인했다.
- 영웅명 검색, 즐겨찾기 토글, 겐지 상세 라우팅을 실제 브라우저로 확인했다. 브라우저 JavaScript 오류는 0개였다.
- 외부 웹폰트의 load 지연으로 일부 초기 QA 실행이 중단됐다. 최종 실행은 폰트 대기 상한과 CSS 적용 대기를 두고, 폭별 페이지를 격리하여 모든 검사를 통과했다.

통계 API 네트워크는 **실제로 저장된 3지역 v2 JSON**으로 인터셉트했다. 새 API 수집/원격 호출 검증이 아니며, 없는 통계 값을 만들지 않았다. 영웅 메타데이터/겐지 상세는 기존 검증 fixture를 사용했다. 화면의 HOW 조회 시각은 테스트 앱의 조회 시각이며 원본 스냅샷의 집계 마감 시각이 아니다.
