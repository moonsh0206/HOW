# 모바일 최근 패치 상위 접기

## 원인과 정책

기존 패널은 첫 3개 변경을 항상 표시했다. 긴 설명과 다른 모드 안내가 함께 쌓이면 모바일의 다음 그래프가 아래로 밀렸다.

- 600px 이하에서 **표시되는 최신 모드별 변경의 합이 2개 이상**, 또는 단일 변경의 현지화된 설명이 100자 초과/기술명이 40자 초과이면 기본 접힘이다. 이는 UI 밀도 기준이며 패치 판단 기준이 아니다.
- 짧은 변경 하나는 기존처럼 바로 표시한다. 패치가 없으면 패널을 생성하지 않는다.
- 제목·주 모드의 기존 유형 배지·실제 날짜·출처는 유지한다. 개수는 주 모드 변경과 다른 모드 변경을 구분한다. 다른 모드는 그 모드의 마지막 관련 패치이므로 같은 날짜의 전체 변경으로 표현하지 않는다.
- 내부의 3개 초과 변경 `details`와 5v5/6v6/스타디움 구분은 그대로다. 상위를 열고 내부 펼치기를 통해 모든 기존 내용을 읽을 수 있다.
- PC/태블릿(601px 이상)은 상위 버튼을 숨기고 내용은 항상 표시한다.

## 상태·접근성·모션

`patchDisclosure.js`는 모바일 선택 상태와 실제 현재 표시 상태를 분리한다. PC에서는 항상 펼치되 다시 모바일로 돌아오면 사용자가 선택한 상태를 복원한다. 동일 영웅의 통계/지표 갱신과 전체 상세 DOM 재생성에도 상태를 이어받고, 다른 영웅으로 이동하면 초기 상태를 적용한다.

내부 details는 배열 위치 대신 모드·패치 ID·구분 키로 복원한다. 데이터가 바뀌어도 다른 모드에 기존 상태를 잘못 적용하지 않는다. 제거된 패널의 미디어쿼리 listener와 모션을 정리한다.

버튼은 최소 44px, `aria-expanded`와 `aria-controls`를 제공한다. 닫는 내용은 즉시 inert 처리하고, 완료 후 hidden 처리한다. 내부에 포커스가 있으면 상위 버튼으로 이동한다. PC 전환으로 버튼이 숨겨질 때는 공식 출처 링크로 포커스를 옮긴다.

본문 높이는 현재 실제 높이부터 `scrollHeight`까지 **250ms ease-out**으로 변화한다. 이전 애니메이션을 취소하고 현재 높이에서 이어가므로 연속 클릭에도 최종 상태가 정확하다. 화살표도 같은 시간으로 회전한다. Reduced Motion은 즉시 전환한다. 고정된 카드 높이로 내용을 삭제하지 않는다.

## 변경 파일

- `src/views/heroPatchView.js`: 실제 개수, 상위 body, 내부 details 식별자.
- `src/views/patchDisclosure.js`: 새 모바일 disclosure 동작.
- `src/views/heroDetailView.js`: 상위/내부/포커스 상태 복원 및 정리.
- `src/styles/detail.css`: 모바일 컨트롤과 화살표, PC 표시 보존.
- `src/i18n/{ko,en,ja}.js`: 상세 보기 및 모드별 변경 개수 문구.
- `tests/patchDisclosure.test.js` 및 두 QA 스크립트.

## 실측

동일 headless Chrome, 높이 900px, 겐지·한국어·전체 전장. 아래는 실제 앱 배치 측정이다. 이미지는 전후 동일하게 차단했고 통계 응답은 캡처 자료와 테스트 전용 값을 사용했다. 패치 내용은 기존 실제 `notes.json`이다.

|너비|기존 패치 높이|기본 접힘|펼침|그래프 Y 기존→접힘|
|---|---:|---:|---:|---:|
|320|208.39|121.80|257.80|997.28→910.69|
|390|190.39|121.80|239.80|974.19→905.59|
|430|190.39|121.80|239.80|974.19→905.59|
|1280|202.39|202.39|202.39|768.58→768.58|
|1440|202.39|202.39|202.39|768.58→768.58|

390px에서 기존 대비 그래프 도달 거리는 **68.59px 감소**한다. 새 UI의 펼침→접힘 차이는 **118px**다. 뷰포트 900px의 그래프 시작까지 필요한 스크롤은 74.19→5.59px다. 그래프를 무조건 첫 화면에 넣지는 않았다. 실제 변경 개수와 언어에 따라 높이는 달라진다.
