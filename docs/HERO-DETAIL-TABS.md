# 영웅 상세: 통계 중심 전체 정보 탭

2026-11-09. 현재 로컬 코드를 기준으로 View/CSS와 관련 검증만 변경했다.

## 구조

이전에는 통계 요약과 맵 통계가 탭보다 앞에 있었고, 기술/특전 탭을 선택해도 통계가 공통으로 남았다. 이제 `영웅 배너 → 탭 → 선택한 탭 내용` 순서다.

- **전체 정보**: 전용 `#detail-overview` 안에 요약 통계, 그래프/현재값/관측 정보, 메타 점수, 즐겨찾기/통계 정보, 패치, 카운터, 시너지, 지속 능력, 기존 맵 통계를 배치한다.
- **기술·패시브**: 기존 기술 카드·설명·시연 영상과 지속 능력을 제공한다. 영웅 고유 패시브가 실제로 제공될 때 기존 별도 섹션을 유지한다.
- **특전**: 기존 Minor/Major 카드·OverLooker 선택률/횟수/막대·출처를 그대로 사용한다.

PC는 맨 위 4개 지표가 전체 폭을 사용하고 아래 본문은 큰 왼쪽 그래프/정보와 오른쪽 패치/카운터/시너지/지속 능력으로 나뉜다. 600px 이하에서는 요약 2×2 → 패치 → 그래프/관측·메타 점수·즐겨찾기/통계 정보 → 카운터 → 시너지 → 지속 능력의 1열이다.

CSS order로 화면만 뒤집지 않고 실제 DOM도 이 순서로 생성해 모바일 읽기/키보드 탐색 순서를 맞췄다. 별도 모바일 복사본이나 중복 ID는 없다. 지속 능력은 활성 탭에 한 번만 렌더링하며, 특전 카드 원본 노드는 탭 전환 시 재생성하지 않는다. 해시 경로는 이전과 같고 링크 기반 탐색과 뒤로 가기를 유지한다.

영웅 배너/소개 더보기·필터·그래프 3지표 선택·패치 설명·즐겨찾기는 유지했다. 이전 사이드 wrapper에 의존하던 CSS/테스트를 새 overview grid로 바꾸고 사용하지 않는 wrapper 규칙을 정리했다. 계산 로직은 Controller/View에 추가하지 않았다.

- `src/views/heroDetailView.js`: 탭 바로 아래 전용 패널, 요약 카드 분리, 콘텐츠 순서/표시, 지속 능력 중복 방지.
- `src/styles/detail.css`: PC 본문 2열·요약 4열, 모바일 본문 1열·요약 2×2, 공통 카드 스타일.
- `tests/detailTabStructure.test.js`: 탭별 격리·DOM 순서·특전 노드 보존·지속 능력/그래프 단일 렌더링.
- `tests/counters.test.js`, `tests/metricHistory.test.js`, `tests/officialPatches.test.js`, `tests/pickHistory.test.js`: 변경된 DOM 위치를 반영. 기존 데이터/행동 기대값 유지.
- `scripts/qa-detail-tabs.cjs`, `docs/qa/detail-tabs/`: Chrome 스크린샷과 동작 검증.

## 보호 범위와 남은 제약

Meta/티어 정책·API/통계 모델·원본 스냅샷·패치/카운터/시너지 데이터·OverLooker 데이터·Controller·기본 필터·홈 배너/로고는 변경하지 않았다. Git diff에서 해당 보호 경로 변경 없음. 기존 로컬 작업을 초기화하지 않았다. Commit/Push/PR/배포 없음.

모바일은 읽기 순서를 우선한 1열이므로 긴 패치를 펼치면 그래프까지의 거리가 늘어난다. 첫 화면에 전체 항목을 강제로 맞추기 위해 글자를 과도하게 줄이거나 내용을 자르지 않았다. 공통 헤더와 4개 조회 필터는 기존대로 남아 있어, 높이가 낮은 화면에서는 통계 아래 내용을 보려면 스크롤이 필요하다.
